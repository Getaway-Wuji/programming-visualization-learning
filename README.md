在项目根目录运行：

```powershell
pwsh -NoProfile -File scripts/setup.ps1
pwsh -NoProfile -File scripts/task.ps1 ci
pwsh -NoProfile -File scripts/task.ps1 build
pwsh -NoProfile -File scripts/task.ps1 dev
```

打开[开发页面](http://127.0.0.1:5173/)。服务器只绑定本机，端口被占用时不会自动换端口。第一次先完成build，避免缺少WASM或内容资源。

## 完整学习流程

1. 从首页进入课程，打开小节，阅读后点击“确认已学习”。
2. 进入本节练习，默认从仅有main与题目输入的空解答开始。可直接写C代码，或显示教学积木，在同一EDIT文档内双向编辑；自动模式消费本节指导推荐。可主动展开分层提示，或在新标签页查看课程示例；“改错练习”保留独立错误稿，两种起点各有本会话草稿。代码暂时错误或不支持同步时保留原文，并使旧运行失效。
3. “运行本组”真实执行首组输入，不保存通过或积分；“准备代码”仅重新生成源码。点击“提交练习”后，同一解答必须顺序通过该题全部测试组及真实教学要求；首组失败会停止。通过后还须确认实际保存成功，失败可重试原待保存操作。
4. 进入同题复盘，使用播放、暂停、前进、后退、重播及速度选择。当前游标的变量、数组、输出和源码高亮来自同一份真实轨迹。
5. 对照小节完成清单核对已保存的学习确认和必修题通过，再进入下一小节。查看积分和每日目标，在设置中保存基础形象或未来目标，再刷新核对。完整新增操作见[P0.5-07使用说明](项目文档/交付/P0.5-07-独立练习与完成清单使用说明.md)。

小节完成需要阅读确认和必修题历史通过。首次小节/练习/案例观看分别为20/10/5分；默认每日目标为1题、1小节、0案例，同日首次达成另5分。32课32题同日首次完成为965分，首次完成一个案例观看确认后为970分；重复学习、刷新、回退和重播不会重复发首次奖励。原六课档案升级后显示兼容的6/32进度，历史账本及已打开日期的目标保持，升级本身不补发奖励。

基础形象有嫩叶、芽苗、方块、星光四个预设和强调色；保存完成后刷新保留。五档等级按已入账积分0/30/100/200/400派生，显示学习积累。目标改变按未来生效规则处理，不能借此反复获取当日日奖。

## 案例、输入与播放

七个案例为变量赋值、分支判断、while/for循环、数组遍历、冒泡排序、选择排序、二分搜索。手动整数输入范围−999～999、数组最多30项；空数组填`[]`，循环次数0～30。二分搜索要求非递减，允许重复并返回首次匹配位置，乱序不会被静默排序。

在“运行内容样例”填写参数，点击“应用输入并准备”，检查只读完整源码与本次输入，再点击“运行示例”。可生成随机数据、保留种子后复现，或恢复示例输入。改输入/积木、切换案例或离开页面会使旧运行和播放失效。

对已发布且确切匹配的模板，准备可读取构建期由真实Rust生成的输入声明，首次运行才按需加载引擎；不匹配模板仍走受限Rust准备。实际执行再次校验完整源码和绑定。冷/暖Module由实际加载状态定义，每次运行/测试组均使用新Worker，最多一个活动Worker。

1×每500ms推进一个教学步骤，支持0.25×、0.5×、1×、1.5×、2×、4×。聚焦“执行播放工作区”后可用空格播放/暂停、左右方向键单步；表单控件保留原生键盘行为。隐藏页面会暂停，返回后手动继续。默认500ms步进不等于连续像素变化60fps。

案例奖励需要真实运行、完整可见地逐步观看后主动确认；被动浏览、拖到末尾、重播和再次确认不能刷分。

## 本地数据与执行边界

全部学习档案统一保存在当前浏览器、当前origin的IndexedDB中，包括设置、进度、账本、目标、打卡与形象；不使用账号、云存档或localStorage镜像。不同浏览器、不同端口、127.0.0.1与localhost分别拥有独立档案。无痕窗口关闭、浏览器清网站数据或设置里的确认清除会丢失该档案。

保存事务成功后才显示已保存；配额、权限、冲突或损坏会明确提示，不能确认的积分不冒充已入账。未保存草稿只在当前页面内存。设置的“本地数据”清除先说明影响并确认；原子清除后旧页面/迟到事务不能复活旧档。

公开静态资源需从页面所在站点下载；C程序解释执行位于当前浏览器的DedicatedWorker，不发送给执行服务器，Rust不持久化个人档案。本地保存与网络资源下载是不同边界，不承诺首次完全离线。

源码、输入、随机种子、轨迹和输出为临时运行数据，不写入学习档案，刷新后失效。前端消费统一Step DSL，不重算算法，不运行GCC、原生用户程序或JavaScript动态代码。n30、1000ms运行安全截止及WASM128MiB上限保持；失败、取消、超限与正常完成分别呈现，旧结果不能覆盖新运行。
