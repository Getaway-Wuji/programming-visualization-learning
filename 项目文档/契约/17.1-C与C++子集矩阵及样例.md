## 最小可核对样例及预期

以下是要求17.2实际执行的测试向量，输入均来自页面请求，显示源码即被执行源码。除代码可见输出外，要求检查真实输入游标、状态与全逆。

**C正常：** 输入`[7, -2]`，输出`5`；输入`[7]`在第二次读取诊断且`b`不写、游标保持1。支持数组元素目标 `&a[0]`；`&a[2]`对于2项数组诊断越界且不消费。

```c
#include <stdio.h>
int main() {
  int a; int b;
  scanf("%d", &a);
  scanf("%d", &b);
  printf("%d", a + b);
  return 0;
}
```

C拒绝：`scanf("%d%d", &a, &b);`、`scanf("%d", a);`、`int n = scanf("%d", &a);`；缺stdio头亦拒绝；`if (0) { std::string s; }`仍静态拒绝。

**C++字符串正常：** 输入两行`["aba", "a"]`，输出`3`后`a`；改为`["", ""]`，输出`0`，不得访问`s[0]`。仅给一行必须在第二次getline报告输入不足；31个字符或`é`在请求校验拒绝，`s[3]`在长度3时报运行越界。

```cpp
#include <iostream>
#include <string>
int main() {
  std::string s;
  std::string p;
  std::getline(std::cin, s);
  std::getline(std::cin, p);
  std::cout << s.size();
  if (s.size() > 0) { std::cout << s[0]; }
  return 0;
}
```

复制独立性：`std::string t; t = s;` 后再次getline修改s，t仍为原值；逐步回退同时还原s/t、输入游标、输出和作用域。拒绝`std::getline(std::cin,s,',')`、`s[0] = 'x'`、`s + t`、`std::cin >> s`以及运行输入包含换行/NUL。
