# 02.3 事务、日期与奖励幂等

契约：**SAVE-TX-01 1.0.0**，2026-10-14；承接[LEARN-EVENT-01](./02.1-学习事件与奖励边界.md)及[02.2执行身份](./02.2-执行请求与生命周期契约.md)，不改变七类事件业务谓词或正式分值归属。

## 1. 命令与提交

统一学习入口先在内存验证当前执行身份、真实完整题目/观看事实，再产生封闭命令：contractVersion、generation、eventId（随机UUID，同一次事实/保存重试保持）、occurredAt、localDate、event字段（02.1白名单）、当天goal快照引用。只有适配器私有可信路径能创建学习命令，页面不能传`validated:true`/任意通过布尔值。合成模型里的learn操作只表示前置已满足的测试事实，不冒充运行验真。执行证据/命令本体只在内存，receipt不保存它们。

有效提交顺序：

1. 捕获事实时读取已打开的本世代meta及当天已冻结goal；核对当前运行/内容仍有效，固定eventId/time/date和包/实体修订。跨日打开新goal必须先完成goal.open事务，失败则未保存，不猜新日期配置。挂起恢复先刷新meta/日状态。
2. 开含meta的readwrite事务，重读schemaVersion/generation与当前数据；未知版本/错误世代停止。查receipt，逐字段核对eventType、subjectRef（含version）、packageRef、learningRevision、result、goalVersion、occurredAt、localDate及attempt专有类别/caseKey；同ID全部相等返回先前已保存结果，任何差异拒绝`S_EVENT_ID_REUSED`，不能重写。receipt存在时仍先检查世代，不能用旧回执复活清除数据。这个检查先于内容升级后的兼容判断，原重试只能确认原版本已保存，不能将它宣称为新规则通过。
3. 检查内容精确Ref/learningRevision、日期/goal引用和业务谓词。旧缓存整档不得put。普通事实在当前行上合并，正面历史不被失败撤销；目标/偏好/头像修改用expectedRevision CAS。两个不同主体并发事实可在事务内重读后合并，不要求它们共享旧revision。
4. 学习确认/题通过后，在同一事务根据当前兼容确认和全部必修兼容通过派生lesson.completed；**只有触发新学习事实时**派生，内容刷新/迁移/旧状态扫描不发事件。当日新study-confirmed可为已完成小节产生当日复习事实；同日重复只一次。派生事件ID为`<父eventId>:lesson:<稳定lesson.id>`，根receipt即涵盖派生原子效果，不另存随机ID。
5. 对三类每日事实add唯一日/type/规范主体键；查首次source/规范主体或日source/date奖励键，首次建立pending权利，已有则不重奖。当前有效公共policy可在同事务将pending转posted一次；不得用新随机eventId/新版内容/新目标版本绕开键。
6. 用同日三类去重行计数，非null targets逐项满足才将goal.achievedAt从null置**第一次使该日目标满足的有效触发事实时间**（不是该日第一条无关事实时间），并派生日奖权利。迟到旧日命令仍使用原occurredAt；该日已经达标时不改achievedAt。全零目标非法。保持已达标和日奖，即使后续内容升级；目标快照在当日不可改。
7. revision+1并保存根receipt。任何行失败/关系不合法主动abort全部；transaction.complete后重新从DB读取meta核对活跃世代（不是只比本标签缓存），发布已保存并广播最少失效提示。发布前被清除则返回`S_GENERATION_STALE`，UI重新读取，不应用旧成功。之后发生的清除在后续读/写/focus再失效；无法原子保证读取确认后永远不再清除。

仅“重复ID”的receipt路径不递增revision；不同eventId同业务事实可接受最少receipt但奖励/日计数仍去重。receipts不自动过期；配额不足不删除去重键。刷新只读取，不制造新事实；内存未提交队列不写localStorage，也不承诺刷新可恢复。

## 2. 日期、目标与时钟

timeZone在首次新世代初始化固定，IANA名通过Intl验证，失效不暗换UTC/重新分桶而进入只读恢复。UTC发生时间可用时区转换确定localDate，必须在事实产生时绑定；保存于23:59、午夜后重试仍原日。日期加一天用公历运算，不能用24小时毫秒代替（日长可能受DST影响）。当地日界线为该时区日历0:00，不以UTC午夜归档。

goal.open以当前观察日创建一次不可变快照：goalVersion取当时goalTemplate.revision；template=null时goalVersion=1、targets=null。模板配置/修改保存为新revision，仅未来尚未打开的日使用，不修改已有goals。P0目标项范围1..100或某项0，具体推荐组合由11.2冻结。**正式一期11.2必须在首次goal.open之前装载有效推荐配置、保存初始模板；配置不可用时明确目标暂不可用，不先冻结一个null今日再假称首次设置可立即打卡。** null快照用于工程未接奖励目标阶段/资料故障，不是完整一期正常首次使用路径。新日不自动打卡；需要该日新的真实有效三类事实。UTC时间与localDate关系必须一致，重试不得重采时间/goalVersion。

可在后台跨日后继续临时学习，恢复时重新打开新日并核验，不能把昨日缓存目标当今日。一个标签修改模板、另一个标签首次开日，以meta重叠事务实际提交顺序决定快照，模板CAS冲突提示刷新。已打开的今日设置修改显示“后续日期生效”，不伪称今日目标已换。配置业务校验须收紧到当前可用的6题/6节/7案例等实际数量，结构上限100不代表可推荐不可达目标；内容删除后已冻结目标若不可达须明确说明，不能改旧快照或补发日奖。

系统时区改变不影响世代timeZone；时钟回拨/跳进可能产生此前/未来日期，唯一日键防止对同一日重奖，但不能证明日期真实性。检测明显倒退时显示本地时间异常/请校准，不自动删历史或换世代；校准后仍复用原日去重。没有联网校时、账户或可信防作弊承诺，不能凭时钟变化清空账本。

独立`reward.settle`用于11.1有效公共policy就绪后的pending入账：在含meta/ledger的事务重读世代、版本和权利；只把pending的points/policyRef/status成对更新一次并revision+1，已posted不动。加载晚到的旧世代拒绝；settle不制造新的权利、每日事实、小节完成或打卡。没有pending或全部已posted时不增revision。事务失败保留pending，重试同样安全；正式政策/阈值仍由11.1/11.3冻结。

## 3. 原子失败与清除

| 情形 | 规定结果 |
|---|---|
| quota/禁用/abort/连接关闭 | 完成事件之前一律未保存，旧有效数据保留；原命令内存幂等重试 |
| complete后ACK丢失 | 重读receipt核对，不重新生成事实/日期/奖励 |
| 两标签同题不同eventId | 两receipt可存在，首次奖和同日题计数各一，历史通过合并 |
| 两标签不同题 | 事务内合并全部结果；不把第二份旧内存存档覆盖第一份 |
| 目标/头像/设置旧revision | `S_REVISION_CONFLICT`，不隐式last-writer-wins；用户刷新后新操作 |
| 通知丢失/标签挂起 | 写前和恢复时读取meta，通知不是正确性条件 |
| 用户清学习数据 | 本标签先暂停学习入口/终止Worker/失效临时上下文，再单事务清全部九store并放新meta/default settings/avatar；其他标签旧命令即使漏通知也世代拒绝 |
| 清除事务失败 | 旧持久数据仍在，显示未清除，不宣称成功；本标签临时运行已失效，可读取恢复 |
| 浏览器删除整个DB | 新开初始化新随机世代；所有旧命令禁止自动建库或换世代重试；若存储不可用只临时学习 |

清除范围只本DB和本项目内存，不能用localStorage.clear或清同origin其他DB；不承诺公共缓存/浏览器底层擦除或删除用户已导出文件。新世代首次奖励可重新开始，这是用户明确清除后的新本地档案，不是可认证账号终身权益。

## 4. 错误与派生数据

稳定错误码：`S_VERSION_UNKNOWN`、`S_GENERATION_STALE`、`S_REVISION_CONFLICT`、`S_EVENT_ID_REUSED`、`S_RECORD_INVALID`、`S_CONTENT_INCOMPATIBLE`、`S_DATE_INVALID`、`S_STORAGE_UNAVAILABLE`、`S_QUOTA`、`S_ABORTED`、`S_UPGRADE_BLOCKED`、`S_MIGRATION_UNSUPPORTED`。仅码/存储阶段临时展示，不持久日志化档案/异常正文。

学习状态与saved/unsaved/conflict/readonly状态独立；未保存可显示本次临时完成，积分只能明确区分已入账/pending/本次未保存。清除/迁移不得通过总积分缓存推导补奖。旧失败记录不撤销兼容历史通过；当前编辑使运行失效不等于删除历史。等级/进度百分比/当前完成是读取投影，不是能被页面写true的权威行。
