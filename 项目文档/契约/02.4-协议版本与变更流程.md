# 02.4 协议版本与变更流程

契约：**CHANGE-01 1.0.0**；2026-10-14，Codex-02.4协调窗口。输入02.1—02.3十项1.0.0契约及DEC-001—006 V1.0，不升版或改写这些既有文件。本规则管理公共变更的归属和证据，不是产品运行消息、账号权限或云审核服务。

## 1. 版本维度与冻结

| 维度 | 已冻结值/负责处 | 不能混用 |

| EXEC-01 / STEP-01 / DIAG-01 / JUDGE-OBS-01 / JSON-INT-01 | 1.0.0，02.2 | 5个版本显式匹配；源码revision/run不是契约version |

| 引擎及构建 | EXEC engineRef id/version/buildId，03.1/03.3发布时核验 | 夹具engine.fixture不是正式引擎、buildId不是用户内容哈希 |

当前消费端只接受精确登记的版本、字段、事件和枚举。主/次/补丁号不授权自动兼容：未知version/新可选字段/事件仍会被旧封闭Schema拒绝，不能“忽略继续”。增加可选字段也须升级双方显式支持表；改变事件边界、游标/逆数据、整数/字节编码、判定、日期/奖励键视为不兼容语义。纯文档纠错可做补丁，但同id/version不可改写已发布公共包/实体，已冻结夹具的修正也需登记新fixture版本及影响，不能悄改黄金答案。

执行不兼容先拒绝，不回显陌生请求版本当成功；内容新包非法保留旧已验证包/说明版本或不可用，不混装；SAVE未知新版只读不降级写回/清空。显式内容patch兼容还需同ID同learningRevision及acceptedPriorVersions；改判定须增learningRevision、保留旧历史重新满足，首次奖励不自动重发。ID迁移须SAVE-MIGRATE的等义manifest、精确兼容链与新侧已有行保护，不把新ID当新领奖机会。

## 3. 影响定位与变更记录

[登记样例](./02.4-变更登记样例.json)的impactRules将上述角色映射到明确任务集合；引用规则由[共享资料检查](../验收/02.4-共享资料检查.mjs)核对任务ID存在及实例影响集合完整。changedFields每项记录contractId和JSON Pointer（语义段落用已登记的语义key），不得只写“改Step”或“修存档”。角色可有交叉，但唯一实际文件写入者只在台账指定。

每份变更卡包含id/status/purpose、旧新版本、字段/语义差异、compatibility分类、触发impactGroups、计算后affectedTasks、requiredOwnerRoles、fixtureIds、旧数据/运行处置、迁移/回滚、验证及批准证据。缺任一受影响方不得合入；运行语义/预算变化还需对应DEC升版，内容判定变化需learningRevision决议，存档变化需完整upgrade/恢复recipe。新增P1/P2数据必须先过阶段门槛并更新白名单，不能用SAVE扩展袋绕过。

fixtureIds需能解析到唯一共享索引条目；包含所有相关正常、非法、超限、恢复及旧新版本案例。受影响任务是集合，不是“全部后续”空泛文字。公共合成文档/fixture文件可用SHA256检测冻结产物变化；**绝不对用户源码/输入/输出/轨迹制作持久哈希指纹**。读取缺文件/哈希不符是资料基线漂移，先停下协调，不自动刷新索引掩盖改动。

## 4. 处理流程

1. 提议：登记changedFields/旧新语义/版本、前置、范围和初步影响，status=proposed；主窗口核实字段负责人及文件独占，没有批准前不改共享文件。
2. 裁决：相关owner确认compatibility、版本/学习修订/旧运行失效/旧历史与奖励/迁移回滚及阶段预算。先更新impactGroups并算affectedTasks，不因某模块暂未实现就遗漏它。
3. 双方验证：编写旧可读/旧拒绝、新正常/坏例/边界及必要迁移夹具；按[验证说明](./02.4-双方兼容验证说明.md)分别记录资料、Rust核心、浏览器真实链路，不用文档pass代替运行pass。
4. 合入：唯一文件owner集成；根配置/依赖/锁图由03.1指定负责人处理。记录每方证据和批准，再冻结新版本/索引/哈希。产品已存在后必须真实生产者+消费者+存储（若受影响）通过；否则状态待验收，不能仅“审过设计”上线。
5. 收尾：协调更新台账/版本索引/交接，旧卡和旧证据保留；未解失败阻止新基线发布。回滚静态包/引擎需版本匹配；SAVE已升级不能旧版降级写回，回滚实现须仍读新库或停写，不能删库回滚。

当前“accepted-document”仅登记已验收设计基线；所有示范提案为`proposal-fixture`、批准为空、真实验证为空，**不授权升级到2.0.0或修改任何既有契约**。随机generator的算法/种子解释仍由07.2冻结；本任务只登记格式/可复现输入要求，不杜撰算法或宣称任意seed已可复现。
