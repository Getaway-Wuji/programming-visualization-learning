# 02.2 Step DSL 状态与源码映射

契约：**STEP-01 1.0.0**；日期：2026-10-14。依据[DEC-005](../架构决策/02.2-StepDSL可逆与编码决议.md)、[P0-C](../架构决策/01.3-一期C子集支持矩阵.md)。配套[执行契约](./02.2-执行请求与生命周期契约.md)、[诊断/观测](./02.2-诊断预算与判题观测.md)、[Schema](./02.2-执行与轨迹.schema.json)。

## 1. 源码与身份

byteRange={start,end}为UTF-8字节0基半开区间，0≤start≤end≤源码字节数，端点不得切断Unicode编码或CRLF中间；零长位置可用于EOF/缺token。Rust nodeMap为扁平AST节点表：nodeId、kind、parentId、byteRange；kind封闭为function/block/declaration/assignment/expression/condition/output/return/break/continue/empty/if/while/for。ID按该sourceRevision的AST确定性先序n1,n2…分配，每次实际执行动态对象/作用域/帧另分o/s/f ID。nodeId不能跨sourceRevision引用，循环同一声明node重复执行产生不同objectId。

行/列仅为显示投影：行列均1基，列按Unicode标量计，tab算1个字符而非视觉宽度；CRLF整体换行一次，LF和单CR均各换行。源码不归一，UTF-16编辑器坐标按同一原字符串逐标量换算，补充平面字符占两个UTF-16码元但一个列，不以UTF-16长度替代UTF-8偏移。nodeMap的parent范围必须包含子范围；解析前错误可用直接byteRange而无nodeId。

每step.location为source（nodeId及edge=start/whole/end）或synthetic（reason及可选anchorNodeId）。source整节点、start第一标量、end最后标量用于高亮；块退出可用块节点end定位闭花括号。synthetic原因枚举initial-state、implicit-return、pre-execution、adapter-cancel、adapter-deadline、module-load、worker-failure、protocol-validation、encoding-failure。未定/未知reason不能假装合法无源码事件。

游标0用synthetic initial-state，可锚定main节点；游标k>0的高亮/当前读写/教学观测取step[k-1]，是刚完成的步骤，不是下一步。terminal失败位置仅在尾游标额外展示，暂停/后退不改步骤事实。blockMap的一个块可覆盖多个节点/步骤，同一行可多步；Rust根据确切范围交集和声明身份解析映射，拒绝重复blockId、越界/过期sourceRevision和错误绑定，不用名字串替代AST映射。

## 2. 可恢复状态

initialState显式包含下表7项，空集合不是省略字段。P0程序开始前frames/scopes/objects均空，output为空，counters为0，control.phase=ready、nextNodeId指向main；allocator地址从4096、序号从1开始。

| 状态项 | 字段和语义 |
|---|---|
| frames | 有序Frame[]：id/functionNodeId/parentFrameId/scopeIds；P0只能活动main帧，无用户函数/递归；预留父帧关系给12.1 |
| scopes | 有序Scope[]：id/frameId/parentScopeId/nodeId/kind(main/block/for)/objectIds；词法遮蔽按活的声明对象，不按名字覆盖全局 |
| objects | 有序Object[]：id/declarationNodeId/frameId/scopeId/name/kind(int/int-array)/length/baseAddress/defaultValue/cells；scalar长度1，数组正容量 |
| cells | 对象内按index升序的稀疏{index,value}[]；value为int32，未列项用defaultValue（null表示未初始化）；不保存等于defaultValue的冗余项 |
| control | phase(ready/running/returned)、nextNodeId、activeFrameId、returnValue、flowStack[{nodeId,stage,iteration}]，stage为block/init/condition/body/update；记录控制位置/循环阶段，不供前端重执行 |
| allocator | nextAddress/liveBytes/nextObject/nextScope/nextFrame；对象槽4字节，地址按4字节对齐单调分配、仅教学虚拟地址，不是宿主指针；本run不复用退役ID/地址 |
| output、counters | output为实际虚拟文本；counters为comparisons/scalarWrites/arrayWrites/swaps，均非负整数，可逆恢复 |

对象存活量=全部活对象length*4，scope/frame引用闭合、无环，所有对象只归一个活作用域；有序表在销毁/恢复时保持精确次序。释放减少liveBytes，单调nextAddress不回收；逆操作恢复旧allocator全部字段。12.2如需地址复用/指针/新类型，须另冻分配/生命周期增量，不将当前地址当宿主真实地址。

绑定resolvedBindings为bindingKey→declarationNodeId；当前活object由真实声明执行映射，不能用同名替身。逻辑数组视图长度来自该run input及绑定n，不按存储容量显示占位。decl N>30不是语法错误，按内存预算分配。

## 3. 原子教学步骤

一步成功提交state变化及观测，失败动作不部分提交。seq从1连续到K≤20000；纯表达式的内部读取/算术/比较只作本步有序观测，不逐AST节点增加教学步数。检查点和帧动画不是步骤；以下边界固定，后续不能为预算悄悄合并/删除。

| step.kind | 原子范围 |
|---|---|
| program.enter | 创建main帧/主作用域，控制进入程序；对应main节点 |
| object.declare | 创建未初始化对象及声明绑定，改变所属scope和allocator；**独立于初始化**，int x=x失败仍保留真实未初始化对象 |
| value.initialize | 标量初值求值并写入；数组整次非空字面量列表及余项补0一次初始化，defaultValue=0+稀疏例外压缩；无初始化不追加该步 |
| value.write | 一条标量/数组赋值：先检查左位置，再完整求右值，成功后一次写；读/比较按真实顺序观测 |
| condition | if/while/for的一次完整条件判断，更新控制位置；短路右侧不产生虚构读/比较；for空cond为真实true并定位其for节点source |
| scope.enter / scope.exit | 独立块或循环体的单次建立/销毁；for额外作用域包含init变量、退出时销毁，main作用域并入enter/return |
| output.append | 一次printf所有参数/格式/预算成功才追加完整文本，不能半行输出 |
| control.jump | break/continue一次跳转并同时退出必要内部作用域；break跳过for更新，continue转for更新/while条件；逆数据含全部销毁对象 |
| program.return | return表达式成功后先取判题观测，再退全部scope/frame并记returnValue；隐式main返回0用synthetic implicit-return锚闭括号 |
| nop | 一个真实空语句；仍耗燃料和一个教学步，禁止无限空循环绕过预算 |

for的init/update复用declare/initialize/write，不另重复计步；省略init/update不增加空操作步。每次实际循环体创建新scope；重复出现的nodeId不等于同一动态object。数组初始化的逻辑槽处理仍逐槽计燃料和初始化写数，即使表示压缩；大数组不能省略预算工作。

## 4. changes及逆操作

每一步changes按发生顺序执行，逆向按数组反序应用。before必须精确等于当前值，违反则轨迹非法；after不得被播放器重新计算。所有操作为封闭枚举：

| op | 数据和前进/后退 |
|---|---|
| record | table=frames/scopes/objects，id、index及before/after完整记录或null；创建插入index，删除移除index，替换保留index；逆交换before/after，恢复原表序 |
| cell | objectId、index、before/after为int32或null；当前有效槽须等before，写after；等defaultValue时删除稀疏项，逆写before |
| control / allocator / counters | 单例对象before/after整项替换；逆交换，不能重算控制/地址/计数 |
| output | beforeBytes/afterBytes/append；要求当前UTF-8长度等before、append长度差相等，再追加；逆删除已验证的完整append后缀并验证beforeBytes，不在字节中间截断中文 |

record不能改id/声明归属/容量后冒充同对象，数组初始化允许同一记录由未初始化默认改为0默认及稀疏初值；普通元素更新用cell。同一步内部暂时的依赖缺口只允许来自有序创建/销毁，步提交后必须满足全部状态关系。操作提交前统一预检结果/步数/内存/输出预算，不能删一半scope后失败。

observations只描述该成功原子动作中真实发生的read/evaluate/decision/short-circuit/swap；每项nodeId属于同source。read另给objectId/index/value；evaluate给operator/operands/value但前端不复算，operator沿用P0-C运算符；decision给value/branch(true/false字符串)；short-circuit给skippedNodeId，右侧没有虚构read。&&/||短路的evaluate只给真实左操作数，且同nodeId必须有short-circuit，左值符合跳过条件；未短路二元运算须两项，不用假右值凑Schema。swap给objectId/indices/beforeValues/writeSeqs，为Rust验证的教学标注，不新建一步；须引用两次不同下标的真实写入seq，值确为交换且非自交换，同一次只标一次。失败求值的局部读/已完成表达式可附terminal诊断的有界关联，不写成成功步骤。

comparisons统计实际执行的关系/相等运算，不含逻辑/循环隐式检查、预算检查；初始化及赋值的每个真实int槽写分别计scalarWrites或arrayWrites（包括写相同值），array读不加写数；swap另计且不再次增加两次写数。累积计数随counters逆操作恢复；Rust性能耗时在stats，动画时间不是算法性能。

## 5. 检查点、失败前缀和验证

trace={dslVersion,completeness,initialState,steps,checkpoints}，completeness为complete/prefix。checkpoints含cursor0及每个128倍数≤K的完整state，cursor0须精确等initialState，不必重复末尾非128倍数的状态。跳转用最近前置检查点+最多127步变化；后退一步直接逆changes，不重跑C。检查点全部计编码预算，与前向投影必须逐字段相等，不能把坏检查点当真相。

终止不占原子步：第20001个动作/超预算/失败表达式之前停止，terminal.cursor=20000或真实K；状态仍为真实有效前缀，terminal指出未完成位置。prefix可完整恢复其0..K，但不能观看完成/题目通过。parse/输入/模块失败和硬取消trace=null；合法空前缀K=0与无轨迹有别，不创建假帧或伪步骤。P0空main正常结束仍有enter和隐式return两步；K=0的prefix不是零步成功，不满足02.1观看完成条件。

校验先版本/大小/唯一键/Schema，再节点/对象引用、seq/changes前置值与完整状态约束、计数/观测/检查点及terminal一致性；任一未知kind/op/版本/悬空对象/越界/不实before拒绝整条轨迹，adapter呈协议故障，不跳步继续播放。暂停只改变播放器播放标志，不能改变state/cursor；重播回0，不发学习事件；后退恢复高亮、对象存亡、槽初始化、作用域/帧/控制、输出/地址及计数。

P0 frames只含main；函数进入/返回的定位与父帧/对象引用已有可扩展基础，但用户函数/指针/内存视图仍待P1增量。当前合成夹具验证DSL正逆运算，不证明Rust真实录制、真实播放器或递归语义。
