## 子任务

### 20.1 笔记内容选择与一致性

**前置任务**：16.3、15.2、18.1。

**要做的事**：定义学习记录、错题、解析、快照和来源的打包结构，支持按章节/时间/类型选择；校验版本和关联。

笔记中的C或C++源码使用真实语言标签及对应运行/内容版本，旧C记录不自动改为C++；第21步后新增语言继续按相同身份边界扩展，不用静态对照代码冒充已执行快照。

**交付物**：笔记数据组织与预览。

**验收条件**：选择范围真实生效；源码位置和快照对应；无数据/部分旧内容可理解处理；不会默认导出全部个人记录。

### 20.2 Markdown 笔记导出

**前置任务**：20.1。

**要做的事**：打包可读 Markdown 及本地图片资源，保存标题、课程来源、代码、错题与快照；处理中文和文件名。

**交付物**：Markdown 笔记下载与示例。

**验收条件**：解压后图片引用可用；内容完整可读；文件能在普通 Markdown 阅读器打开；导出不需上传学习档案。

### 20.3 PDF 方案决议与可选实现

**前置任务**：20.1。

**要做的事**：原文要求 Markdown 或 PDF，默认 Markdown 为必交；本任务明确是否增做 PDF。启用则确定中文字体、分页、代码换行和截图方案，并视觉检查。

**交付物**：PDF 取舍记录；若启用则交付 PDF 与检查证据。

**验收条件**：未启用时记为“按决议不启用”，不冒称有 PDF；启用时无裁切/缺字/错页，表格和代码可读。

### 20.4 全量回归、性能与交付验收

**前置任务**：20.2；20.3 已按决议不启用，或启用后的 PDF 实现已验收；17—19 所有必需任务。

**要做的事**：核对需求覆盖矩阵和 22 个明确算法项；回归本地迁移、资源限制、兼容、异常、可访问性和性能；区分本地运行说明与最终部署方案。

**交付物**：三期验收报告、能力矩阵、运行手册、遗留项与第21步前置交接。

**验收条件**：所有承诺项有验证证据；可选未启用项明确；无假 AI/假多语言/假完整 C；本次远期排除项仍未混入。

核对已有C算法不重做，新增16.4—16.9及18.2—18.5的C++源码/引擎/真实轨迹一致；复杂算法不要求其他语言副本。18.6对照、最小算法C++执行和21的通用语言闭环分别记录；21尚未实施不阻塞20.4，20.4通过后才可领取21.1。
