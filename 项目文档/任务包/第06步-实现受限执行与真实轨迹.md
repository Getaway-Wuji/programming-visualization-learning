## 本步骤目标

让 Rust 真实执行教学 C 子集并生成可重放的 Step DSL。

## 开工条件与文件归属

- 前置：第五步验收；02.2 契约冻结。
- 建议修改范围：backend/ 中执行器、状态模型、轨迹和预算模块；共享样例修改由契约负责人合入。
- 范围之外：不靠前端算法重算、硬编码动画或 JavaScript 动态执行替代 Rust 解释器。
- 路径是未来工程建议，03.1 确认后以实际目录为准。每个子任务领取时进一步登记具体文件，不能把父步骤目录视为独占整模块的许可。
- 公共契约、根配置、路由、依赖/锁文件、本地模型、中央进度由指定负责人维护；本窗口通过独立交接提交共享修改。

## 子任务

### 06.1 基本运行状态与控制流程

**前置任务**：05.3。

**要做的事**：实现变量、块作用域、整数表达式、短路逻辑、条件、循环、main 返回和有限输出。

**交付物**：受限执行器基础、正常与错误运行证据。

**验收条件**：结果和输出符合支持矩阵；负数除法/取余规则明确；除零、未初始化读取等有确定诊断。

### 06.2 数组与教学输入绑定

**前置任务**：06.1。

**要做的事**：实现固定数组、索引、读写；将课程和算法配置的输入映射到同一份实际执行程序，保留生成源码映射。

**交付物**：数组执行能力、模板输入适配。

**验收条件**：改变输入会真实改变结果；越界被阻止；展示的代码与实际执行代码一致。

### 06.3 轨迹录制与可恢复状态

**前置任务**：06.2、02.2。

**要做的事**：记录源码位置、变量/数组变化、比较/写入等事件和输出；规定初始状态及恢复机制；后期内存、栈帧语义保持可扩展。

**交付物**：真实 Step DSL、重放一致性验证。

**验收条件**：最终轨迹与运行结果一致；相同程序及输入确定重现；前进 N 步再后退 N 步恢复初始状态；退出作用域及输出能恢复。

### 06.4 执行预算、取消与失败终止

**前置任务**：06.3、01.4。

**要做的事**：限制源码长度、语法深度、步数、内存、输出、耗时和响应大小；支持取消，区分预算耗尽、错误、取消、完成。

**交付物**：预算实现、边界与恶意输入验证。

**验收条件**：死循环、超大数组、输出爆量不能拖垮服务；终止后不继续写轨迹；无文件/进程/网络/任意库访问通道。
