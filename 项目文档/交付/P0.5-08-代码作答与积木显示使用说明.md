# P0.5-08 代码作答与积木显示

在练习答题区使用“积木显示”选择：

- 自动（按课程推荐）：当前前两节默认代码作答，条件、循环和数组四节默认展示积木。
- 始终显示：打开积木，可同时查看或编辑同一份C代码。
- 隐藏：代码使用完整答题宽度，仍可运行和提交。

也可在“本地设置 → 显示设置”修改这一偏好。题内选择即时生效，成功后会显示已保存；保存失败只临时使用，不会冒称已保存，可选择“重新读取并保存选择”或“采用已保存选择”。它与主题、明暗、布局和学习记录分开保存。

积木显示时，点击“编辑 C 并同步积木”进入代码作答；“收起代码编辑”可返回积木配只读代码。隐藏积木会打开代码编辑，保留当前完整原稿。校验通过后，代码与积木表达同一份当前程序；错误稿旁可能保留上次同步的积木，并明确提示历史状态，不能据此运行。仅切显示不会改解答、重新运行或发积分。已挂载积木收起再显示时保留原生画布和撤销操作。

代码需要保留题目的输入声明；语法错误、受控输入被改动、暂未映射的写法会保留原文并说明问题，当前稿修复前不能运行或提交。隐藏积木不会放宽支持语法或教学判定。运行本组只执行第一组；提交练习仍由真实Rust检查全部测试和教学目标，保存成功后才确认通过记录。

独立练习与改错练习各自保留当前会话草稿，切回可以继续。访问设置和同题复盘可保留原稿；刷新、离开本题或清除本地数据仍按临时会话规则处理，不提供持久编辑历史。学习进度、积分和显示偏好保存在当前浏览器，代码在浏览器内的Rust/WASM中执行。
