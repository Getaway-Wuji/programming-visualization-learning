# 一期使用说明

日期：2026-10-23。适用范围：一期P0；[11.5一期交付验收](../验收/11.5-一期交付验收.md)已通过，完整闭环、实际验证与已知边界见该报告和[统一台账](../任务进度与交接.md)。本说明依据当前入口、源码和真实证据提供使用方法，操作说明本身不替代验收记录。

## 在这台已准备好的电脑上使用

项目位置：`D:\Files\Downloads\编程可视化教学平台`。浏览器直接打开HTML文件不能代替启动项目。普通使用不需要账号、密钥、外部数据库或执行服务。

开发入口可直接双击项目根目录的[启动项目.bat](../../启动项目.bat)。它使用项目固定Node启动开发服务器，自动打开[本机开发页面](http://127.0.0.1:5173/)。使用时保留启动窗口；关闭窗口或按Ctrl+C停止。再次双击会检查并打开已运行的本项目；端口被其他程序占用时会提示失败，不自动换端口。

若要演示已构建的一期产品，在PowerShell 7中执行：

```powershell
Set-Location -LiteralPath 'D:\Files\Downloads\编程可视化教学平台'
pwsh -NoProfile -File scripts/task.ps1 preview
```

打开[本机生产预览](http://127.0.0.1:4173/)。预览使用`web/dist/`中的生产静态产物，也只绑定本机。保持这个窗口运行，用Ctrl+C停止。本说明的[完整演示路径](./一期演示路径.md)统一使用4173端口；不要在演示中途换到5173，否则会看到另一份本地档案。

若修改过产品源码或缺少生成资源，先在项目根目录构建，再启动开发或预览：

```powershell
pwsh -NoProfile -File scripts/task.ps1 build
pwsh -NoProfile -File scripts/task.ps1 dev
```

`dev`为开发入口，地址为5173；`preview`为生产预览，地址为4173。也可使用`npm run dev`；它同样转交项目固定Node。已安装Bun时的`bun dev`只是调用入口，不代替依赖安装和Rust/WASM构建。

## 首次准备另一台Windows电脑

这些是当前脚本支持的准备步骤；**11.4未验证全新机器安装，也未验证公网部署**。当前交付的本机实际启动验证与新机器安装是两回事。

前提为Windows x64、PowerShell 7、Rustup，以及Rust MSVC工具链需要的Visual Studio C++ Build Tools和Windows SDK。首次准备需要网络访问Node、Rust、npm与crates.io资源，不需要GCC。复制工程时保留两份依赖锁；不要自动升级依赖或用本机其他Node版本代替固定版本。

在项目根目录逐项执行，前一项成功后再继续：

```powershell
pwsh -NoProfile -File scripts/setup.ps1
pwsh -NoProfile -File scripts/task.ps1 ci
pwsh -NoProfile -File scripts/task.ps1 build
pwsh -NoProfile -File scripts/task.ps1 preview
```

`setup.ps1`准备项目私有的Node24.21.0/npm11.19.0和wasm-bindgen CLI0.2.129，安装精确Rust1.99.0、rustfmt/clippy及`wasm32-unknown-unknown`。它不更改用户默认Rust工具链；`task.ps1`只为该次命令调整PATH。`ci`使用npm锁安装；Rust检查/构建使用锁定依赖。成功后打开4173页面。

维护人员可按改动影响使用以下入口。它们会运行真实检查，不能把这里列出的命令当成已经执行的结果：

```powershell
pwsh -NoProfile -File scripts/task.ps1 env:check
pwsh -NoProfile -File scripts/task.ps1 typecheck
pwsh -NoProfile -File scripts/task.ps1 lint
pwsh -NoProfile -File scripts/task.ps1 format:check
pwsh -NoProfile -File scripts/task.ps1 check:rust
pwsh -NoProfile -File scripts/task.ps1 test
```

完整`check`还包括构建、资料/Schema、开发和预览启动及浏览器测试。浏览器测试另需已安装Chrome、Edge及`browser:install`准备的Playwright Firefox；它与安装版Firefox兼容验证分开。实际一期验证请看验收报告，不把历史退出1的完整检查倒改为成功。

## 能学习和运行什么

一期有3章6小节，每节1道必修练习，共6题24组测试，另有7个可真实运行的案例。练习使用20类教学积木，积木单向生成右侧只读C源码；修改积木使旧判定和旧轨迹立即失效。练习全部测试、正常终态和教学目标同时满足才算通过；小节还须主动点击“确认已学习”。

| 课程 | 必修练习 | 测试组 |
| --- | --- | ---: |
| 变量和输出 | 输出输入变量 | 3 |
| 表达式 | 两倍加三 | 3 |
| 条件 | 非负判定 | 3 |
| while 与 for | 两种循环求和，while/for均须有效累加 | 4 |
| 一维数组 | 指定元素加一 | 5 |
| 综合练习 | 数组求和 | 6 |

七案例为变量赋值、分支判断、循环、数组遍历、冒泡排序、选择排序、二分搜索首次匹配。整数输入为−999～999，数组最多30项；数组空值写`[]`，空白不代表空数组。二分搜索要求非递减数组，允许重复值，返回首次匹配的0基下标，未找到为−1；乱序输入明确拒绝，不自动排序。随机数据可按相同种子和长度复现。

| 当前C教学子集 | 支持边界 |
| --- | --- |
| 程序与整数 | 单一`int main`、有符号32位整数、十进制字面量、局部变量和块作用域 |
| 表达式 | 四则/取余、比较、逻辑短路、括号、一元正负/非；赋值为独立语句 |
| 控制流 | 带花括号的if/else、while、for、循环内break/continue、main返回 |
| 数组 | 固定长度一维int数组、受限常量初始化、下标读写；空教学输入用正容量占位、逻辑长度0表达 |
| 输出 | 有限printf字面量，支持`%d`/`%%`及换行等约定转义；不提供scanf或通用标准库 |
| 错误 | 未初始化读取、越界、除零及int32溢出有明确诊断；失败动作不冒充已完成步骤 |

完整规则见[一期C子集支持矩阵](../架构决策/01.3-一期C子集支持矩阵.md)。`++`、`--`、复合赋值、浮点、指针、结构体、动态/多维数组、自定义函数和递归不属于本期；`#include <stdio.h>`只做教学识别，不展开真实头文件。没有任意粘贴代码执行入口，C++/Java/Python完整执行尚未支持。

播放器读取真实轨迹。可播放/暂停、前进/后退、重播及六档调速；后退恢复变量、数组、作用域和输出。1×每500毫秒推进一个教学步骤，速度仅影响观看。聚焦“执行播放工作区”后，空格切换播放，左右方向键单步；后台页面暂停，回来后手动继续。基础画面提供变量、数组、读写/比较、当前输出和对应源码位置。

## 本地档案、积分和保存

学习进度、真实通过摘要、积分账本、每日目标、打卡、形象和显示设置保存于当前浏览器的IndexedDB。所有偏好共用统一档案，不使用localStorage镜像。档案按浏览器配置及网站来源隔离：不同浏览器、不同配置，或`127.0.0.1`与`localhost`、HTTP与HTTPS、4173与5173，均不会自动共享。

源码、积木草稿、输入、随机种子、完整轨迹和输出只在当前页面临时保留，刷新或关闭不会恢复；练习复盘不是存档。刷新后保留的是已经确认保存的学习与配置记录。存储失败时页面明确显示未保存或临时使用，不能按“已保存”演示；恢复后按页面提示重试。损坏记录保留，受影响数据停止写入；账本不确定时不显示一个跳过坏账的缩水总分。

首次练习通过10分、小节完成20分、案例完整观看并主动确认5分。案例需保持真实变量/数组画面可见，从初始状态逐步看完本次运行；单纯打开、执行、跳过观看或练习复盘均不发案例奖励。刷新、重播、重复提交和同内容的首次奖励去重。

新档案默认每日目标为1道练习、1个小节、案例不设要求；首次主动学习固定当日目标。达到后自动打卡，当日只另奖5分。修改自定义目标用于后续尚未开始的日期，不改写已固定日期；每天每项内容只计一次，新日期的真实复习可计当天进度。日期按档案所记录时区归档，不通过刷新制造学习活动。

首页显示已入账积分、待入账奖励、课程完成数和等级；等级阈值为0/30/100/200/400分。基础形象可选嫩叶、芽苗、方块、星光，并保存强调色。以同一学习日的新档案、默认目标和正常入账完成六课，合计185分；再完整确认一个首次案例为190分，两者均为Lv.3。具体前提和检查顺序见演示路径。

“本地设置”→“本地数据”提供清除入口，须再次确认。清除会移除学习进度、练习记录、积分及防重记录、目标与打卡、形象、显示设置，并丢弃临时内容和待保存操作；本平台不能找回。演示全新档案请另建独立浏览器配置，不清除日常档案。没有云存档、跨设备同步或一期导入/导出备份。

## 执行与网络边界

React页面将同一显示程序与输入交给当前浏览器Dedicated Worker内的真实Rust/WASM解释器，再消费统一Step DSL；前端不重算算法，不执行原生用户程序，不调用GCC或远程执行服务器，不提供用户程序的文件、进程或网络访问。

代码、输入和轨迹不上传到执行服务器；公开网页、课程、积木、WASM等静态资源仍经网络加载。因此“本地保存”“浏览器执行”和“完整离线”是不同承诺，本期不承诺完整离线。生产发布受限课程/练习/案例资源，不把尚未发布的完整CONTENT整包算作已交付能力。

运行有源码、深度、步数、输出、虚拟内存、轨迹和时间预算；当前安全截止1000毫秒、WASM最大128MiB，教学输入最多30项。取消、超限、程序错误和基础设施故障各有反馈；可播放的错误前缀不是正常成功。虚拟资源预算不是宿主真实地址或宿主总可用内存。

## 性能、兼容与本期边界

[11.4](../验收/11.4-异常性能兼容验收.md)在固定参考机、生产构建、网络、视口和前台条件下完成三浏览器3660次执行、90次真实复盘、210次导航；功能回归561项通过。3529次执行≤原500毫秒目标，另外131次偏差保留记录，按用户允许轻微偏差的指示带备注接受：正式矩阵前固定冷Module≤800毫秒、暖Module≤600毫秒；不是宣称原500毫秒全部达到，也不是任何电脑上的延迟保证。正确性、保存、防重复奖励、取消和安全预算未放宽。

三浏览器各30秒播放和Chrome/Edge各50轮产品生命周期有实际证据；安装版Firefox158产品50轮及对应长期内存趋势未测。也未验证自然磁盘/持久配额耗尽、自然坏档、真实旧应用升级、长期零泄漏、持续像素变化的物理60fps、全新机器安装或公网部署。受控故障注入、合成旧档和rAF统计不冒充这些结论。旧Edge懒加载单次问题本轮未复现，根因未证实。

双向积木、学习解锁/编辑快照/拆积木、内存/栈/断点、Bug闯关、图谱/卡片/徽章、算法对比及后续算法属于二期；自定义代码工作台、进阶内容、真实AI、笔记导出等属于三期。账号、登录、云档案、排行榜和多人协作不在建设范围。后续入口由11.5交接说明，不因这些资料存在就提前实现下一期。
