# 排序与长数组使用说明

冒泡排序和选择排序现在默认使用7项：`[7, -3, 0, 5, -3, 2, 9]`。第一次进入、未修改长度时生成随机数据，以及恢复默认输入，均使用7项。可以自行指定0—30项；默认7不是最小长度。空数组和单项仍可以运行。

输入变化后，需要应用输入并准备，再运行示例。页面展示的C源码使用这一份输入，运行画面来自Rust实际执行；修改输入会撤回旧结果。随机数据可用同一种子复现，恢复默认输入也会把随机长度恢复为7。

数组按面板宽度从左到右、逐行排列。每项都有数值、下标及“读／写”标记，调宽分栏、展开运行画面或使用窄屏时会自动重新排列。长数组可向下阅读，不需要为了查看后面的下标反复横向拖动。

所有行使用同一数值比例。正数向零线上方延伸，负数向下，0显示在零线上；大小差别很大时，小值的柱子会接近零线，具体数值仍完整显示。未初始化值有单独说明和斜线纹理，不会当成0。

原有六主题、明暗按钮、左侧导航和工作台布局继续可用。单步后退会恢复对应步骤的值及读写状态。调整外观或布局不会重新执行算法，也不会因为换皮肤发放观看积分。

旧版排序观看记录和已获得的首次奖励继续有效。升级不清除学习档案；再次确认同一案例不会再获得首次观看奖励。如果保存失败，页面会提示未保存并提供重试，保留原档案。
