# 三期运行与部署手册

适用正式1.0.68，2026-11-01；最终验收结果见[三期报告](../验收/20.4-三期当前范围验收.md)，能力和未测边界见[矩阵](../验收/20.4-需求与能力证据矩阵.md)。普通学习功能不需要账号、API Key或AI服务。

## 本地打开

在项目目录双击`启动项目.bat`，或在PowerShell运行：

```powershell
pwsh -NoProfile -File scripts/task.ps1 dev
```

按窗口显示的本地地址打开。固定Node24.21.0/npm11.19.0、Rust1.99.0及项目工具缓存/锁文件沿既有环境；初次安装依赖按README与`scripts/setup.ps1`，不要把当前复用工具缓存的验收称为全新电脑安装验证。

正式构建与本机预览：

```powershell
pwsh -NoProfile -File scripts/task.ps1 build
pwsh -NoProfile -File scripts/task.ps1 preview --host 127.0.0.1
```

构建产物在`web/dist`；`checks/`及浏览器测试harness是内部验收工具，不作为学习站点部署。开发/预览仅用于本地运行，不等于公网发布或正式HTTPS部署。

本轮另交付[静态部署包](20.4-静态部署包.zip)与[逐文件清单](20.4-静态部署包清单.json)：从独立候选源重建的143个文件，均与当前受测产物对应；省去根目录保留的69个旧额外文件。完整解压到站点根目录，保留路径。该包不含内部harness、原教材PDF、个人档案、私钥或网关EXE，没有在本轮公网发布；可选AI网关须按下述方案另行构建/运行。

## 学习与真实执行

- C课程为8章32节、32基础习题；另有4道C和4道C++ Bug关卡，合计40道教学题、172组判题输入。进阶两章四节复用原学习实体，三经典例题/六份C++解法另列，不凭阅读新增完成奖励。
- 七个原C案例保持C；新增算法使用受限C++真实源码。SRS22算法与四个C语法演示分列，范围见[算法目录](../算法目录覆盖表.md)。C工作台只执行已支持C子集；C++算法执行不代表通用C++工作台，Python/Java对照不提供执行。
- 代码和输入由浏览器内Rust/WASM Worker处理。显示源码、源码定位、内存、栈及回退都来自实际接收的轨迹；虚拟地址是教学地址。程序变化、输入变化、取消、离页或超时会使旧运行失效。
- 不支持时保留原文并显示诊断；运行错误/超限只显示真实前缀。不要将GCC风格诊断或编译阶段教学模拟当作运行本机编译器。平台不执行用户原生程序、GCC、系统调用或任意库。

## 浏览器本地数据

当前SAVE9/IndexedDB DB9共17分区，经统一学习服务保存进度、奖励、目标、错题、复习、徽章、薄弱证据与显式C源码草稿等；临时输入/轨迹、临时笔记快照、AI配置/Key不自动持久化。积分按学习事件去重，回退/重播不重复发奖。看见“未保存”时按页面说明重试，不能把临时画面当成落盘成功。

数据与浏览器配置和站点来源绑定；换浏览器、域名、端口、无痕窗口或清除站点数据可能得到独立档案。平台没有账号同步或云备份。IndexedDB可被浏览器或用户清除，不承诺永不丢失。对端标签页清档会使旧运行、旧保存和旧笔记失效；不要依赖关闭旧页保留正在进行的清除。

“本地保存”与“没有传输”分开：普通执行/笔记打包在浏览器进行，但站点仍需加载公开静态资源，不承诺新设备首次打开、清缓存或刷新后完全离线。显式启用AI时另有下面的数据发送边界。

## 笔记与下载

从“学习笔记”按章节、档案时区日期、类型及具体条目选择，默认零选择，先生成预览再下载。旧摘要、当前参考解析与历史作答分别标明；缺失的历史源码不会用教材代码补造。

真实案例/内存观察中的“加入本次笔记”保存当前标签页的捕获副本，最多8份/总8MiB；刷新或清档后消失。来源、语言、源码、输入和游标与捕获状态绑定，后续运行不会重写该副本。

下载UTF-8 ZIP包含`笔记.md`、`说明.txt`、`notes.json`，以及所选快照的`assets/snapshot-NN.png`、`snapshots/snapshot-NN.json`。完整解压后用Markdown阅读器打开，保持资源相对位置。下载发起不等于浏览器已保存到磁盘；失败、取消、档案或选择变化后按提示重新预览/重试。

上限为200条/选择包12MiB、每图8MiB/1440×8192/5秒、Markdown24MiB、ZIP112MiB/19文件/45秒；超限整包拒绝，不截断后报完整。JSON是可检查的附属状态，没有导入或执行入口。笔记导出不是整份学习档案备份。

**PDF按决议不启用。** 浏览器或阅读器自行转换/打印不属于平台已验收PDF能力。下载图片和JSON都可能包含源码、输入和教学状态，分享前自行核对；清除平台档案不会删除已经下载的文件。真实测试示例见[示例目录](20.2-示例/README.md)，非个人档案。

## AI默认关闭

当前默认关闭，普通学习、真实执行和Rust同类题生成可正常使用。规则生成来自Rust验证器，不能称为真实AI出题。真实官方AI成功、模型质量及相关20.4检查按[DEC-P2-012](../架构决策/19.5-默认关闭范围与真实API后置裁决.md)后置，本次官方请求0次；模拟响应只证明工程边界。

日后用户另行启用时，须通过产品设置临时自备受支持服务Key，逐次预览确认发送的最少当前源码/诊断/同游标事实。配置/Key只在当前标签页内存，关闭/刷新/退出清除；不将Key放入命令行、URL或文档。发送经过同源受控Rust网关至官方服务，服务方保留、费用与取消行为不能由“本地保存”推导为零传输、零保留或免收费。现阶段不要求提供Key。

## 最终部署方案与当前实测的区别

普通产品可部署为`web/dist`静态HTTPS站点，须保留JS/WASM/JSON等正确MIME、受审资源路径、内容版本、CSP、缓存策略及HTTPS；WASM需要`application/wasm`。Hash路由无需服务器执行用户代码。先核旧缓存/新资源组合与发布注册，禁止将不匹配内容登记为有效新课程。

如未来要启用API调试助手，另部署对应受审独立Rust网关，并在同源HTTPS上承载或代理`/api/ai/v2/*`，保留固定官方目标、来源校验、预算、取消和Key临时转发边界；不能把纯静态托管说成已具备该网关。详细安全运行条件见[19.4说明](19.4-API调试助手运行与安全设置.md)。

本次没有创建公网托管或更改域名/证书；本地正式构建、预览、受控HTTPS限速测试与GitHub仓库/CI分别记录。GitHub Actions通过只能证明对应工作流执行结果，不证明公网可用、所有浏览器/设备、物理读屏器或真实AI服务质量。
