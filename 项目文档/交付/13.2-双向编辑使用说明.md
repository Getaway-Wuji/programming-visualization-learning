# 13.2 双向编辑使用说明

适用范围：现有六题、20类积木及13.1可映射C子集。原生执行仍为浏览器中的Rust/WASM解释器，学习档案仍在浏览器本地保存。

1. 打开练习，保留本题输入声明。在操作栏选择“编辑 C 并同步积木”，从当前第一组输入的代码开始编辑。
2. 代码变化后会分析当前原文。“代码与积木已同步”表示当前稿可继续运行或提交；代码选区会定位对应积木，选中积木也能定位代码。选择、主题和布局变化不重跑、不改变文档修订。
3. 修改积木会更新同一份代码。代码来源的修改使用局部补丁，保留未受影响原文；范围内注释可能移到语句前，界面会说明。原生字段编辑后的撤销/重做仍可用，不等于持久编辑历史。
4. 语法/输入声明错误或合法但不可映射时，原文保留，运行与提交关闭。积木区明确标为上次有效结构，仅供对照。通过“定位问题”可跳到当前原文的行列、选中问题范围；修复当前代码后重新同步。
5. “运行本组”只运行第一组，不保存通过记录或奖励；“提交练习”真实检查原有全部测试和教学目标。全部通过并实际保存后才显示已保存；重复提交不重复获得首次奖励。

编辑稿始终使用第一组输入。提交后保留的轨迹可能属于最后一组；“查看本组实际执行的 C 代码”显示与该轨迹、输入和源码范围精确对应的只读代码，复盘不重新运行。

收起代码编辑只改变展示，草稿保留。独立/改错模式各有本题临时草稿，切换会使当前运行失效；离题、刷新或清除会丢弃临时草稿，已有真实历史通过仍保留。代码超过32KiB或含不完整Unicode时，本次输入被明确拒绝，保留修改前完整草稿，不截断文本。

当前不支持空语句的积木表示、for头数组赋值、下划线开头积木名称或输出原始tab；这些合法Rust稿为unmapped，可继续改代码。无括号控制体、自增、复合赋值、函数/递归、指针和其他未支持C语法不因此开放。复杂的父块整体替换同时移走带注释子句会拒绝该块修改，避免注释重复；可以继续在代码中修改。

自动/显示/隐藏偏好与课程推荐入口留P0.5-08；解锁、持久编辑历史和拆积木分别留13.3—13.5。代码/输入只在当前浏览器Worker分析和执行，不传往远程执行服务；静态网页资源仍需要加载，不承诺完整离线。
