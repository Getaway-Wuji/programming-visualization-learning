# P0.5-07 独立练习与完成清单使用说明

2026-10-26。适用于目前六道课程练习；代码仍由积木生成并只读，代码作答与双向转换留后续任务。

1. 进入小节并阅读课程，可主动点击“确认已学习”。小节完成清单会显示这条确认是否已保存。
2. 打开必修练习，默认是“独立练习”。工作区仅有main与题目输入声明，请从零添加解答积木；保留题目输入声明，不能用固定答案替代输入。
3. 需要帮助时逐次点击“查看第1/2/3层提示”。“查看课程示例”在新标签页打开只读课程，当前解答会保留。“改错练习”是另一份有待修正的程序，两种起点各有自己的临时草稿。
4. “运行本组”真实执行首组测试输入并提供轨迹、输出和局部检查；即使本组要求满足，也不会保存练习通过或计分。“准备代码”仅重新生成代码；“提交练习”才检查本题全部测试与教学目标。
5. 全测通过后观察保存状态。只有显示“本次真实通过记录已保存”或待保存操作实际恢复后，完成清单才会更新。保存失败时，使用“重试未保存操作”；不必为保存重跑程序。重复提交、复盘和切换主题不会重复发放首次奖励。
6. 清单列出主动确认学习与每道必修题的已保存状态。缺项会指向确认学习或答题区，并移动焦点；全部条件齐备后显示“小节已完成并保存”，可进入下一小节。

切换独立/改错会保留各自完整草稿，同时清除本次运行、轨迹和判定；逻辑编辑也会使旧结果失效。历史已保存通过继续有效。草稿、源码和轨迹只在当前题目会话中临时保留，刷新或离开本题会丢失；这不是持久编辑历史。

学习记录保存于当前浏览器，代码由浏览器内Rust/WASM处理；网页资源仍需要网络。浏览器存储可能被清除或拒绝，未保存操作不能当作已完成记录。
