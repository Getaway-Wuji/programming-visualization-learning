# C代码工作台使用说明

入口：左侧“C代码工作台”（/#/custom-code）。若页面仍显示旧菜单，刷新后进入。当前支持17.1冻结的C教学子集；完整C、任意标准库、C++通用编辑器不在本入口。

1. 在“编辑代码”粘贴或修改程序。函数先定义再调用，支持int、条件/循环、一维定长数组、函数/递归、受限指针和简单struct。
2. 按读取顺序填写整数输入，空格或逗号分隔，最多30项，每项−999..999。scanf限一次一个`%d`及int标量/数组元素地址，须包含stdio教学头；printf支持`%d`、`%%`及换行。
3. 点击“运行代码”。浏览器本地Rust解释执行；运行中可取消。源码或输入改变后旧运行立即失效。错误和预算停止有诊断，点击定位可回到原文对应范围；不会把上次成功结果当本次结果。
4. 在“源码定位与断点”点击行号，播放将在该行真实步骤完成后暂停；“继续”从下一步走。手动前后退不额外命中，源码修改清空旧断点，换输入保留同源行号。没有真实停靠步骤的行不会吸附到别处。
5. 基础、内存、调用栈共享同一游标；内存地址是教学虚拟地址。可调速、回到开头、拖动步骤。窄屏通过“代码与输入 / 执行观察”切换，不重跑；隐藏结果或页面时暂停播放。
6. 点击“保存草稿”后，只有显示“草稿已保存”才代表事务成功。刷新恢复最近成功保存的原始C文本，包括暂时不合法的代码；输入、断点和执行结果不保存。另一标签更新会提示冲突，可先复制保留当前文本，再显式“载入已保存版本”。保存失败保留当前文本并可重试。

源码UTF-8上限32KiB，超长文本保留但禁止运行/保存；沿原执行预算20,000步、1MiB活虚拟对象、16KiB输出、1000ms安全截止等，安全截止不等于性能保证。清除本地数据会删除工作台草稿；未保存修改仅当前页面保留。初次加载公开页面/引擎资源需要网络，执行代码/输入不上传服务端；本入口无账户、云存档或学习积分。
