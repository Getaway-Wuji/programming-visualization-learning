# 16.1 教学讲解与预测挑战

入口：算法与演示 → 变量赋值、分支判断、循环、数组遍历、冒泡排序、选择排序或二分搜索首次匹配 → 运行示例。七例均使用原C程序与浏览器中的真实Rust解释器。现有内存/调用栈观察页保持原功能，本轮预测题只开放这七例。

1. 运行画面下面的“教学讲解”解释刚完成的原子步骤，并列下一步的位置与动作。说明来自当前轨迹的写入、条件决策、输出、作用域及源码行列；“当前已完成k步”和“第k+1步预测”分别标明。
2. 点击“预测挑战”，每例可选择首次初始化、首次关键操作、首次输出三题，共21题。题目跳转使用同一份运行状态；关键操作在变量赋值例为首次赋值，其余为首次条件判断。未执行到的锚点不会补造题目。
3. 每题有三个互斥操作选项。选答后展示你选的动作、真实下一步、源码位置与实际状态变化，正误都有解析。本次运行中答案固定；后退仍显示本次答案，重新运行可再次练习。
4. 同一本地档案每个稳定题目仅首次记分：正确+2，错误−1，之后重复0分。重新输入、重播、换模式、刷新、换日均保持原首次账本；首次错误后重新答对也不补发。预测分不增加课程完成、案例观看、每日目标或成就事实。积分净值可以为负，最低等级进度显示0%。首页“积分明细”可核对题名、日期、规则与正负分。
5. 挑战模式播放会停在尚未作答的检查点，作答后可继续前进。切回教学讲解会暂停并保留当前游标；后退恢复程序状态，单步、调速、原播放快捷键和工作台显隐仍按原规则运行。原内存/栈/断点入口独立保留。
6. 保存失败会明确显示“积分未确认”，可“重试保存原答案”，使用相同答案、发生时间及事件身份。输入变化会使旧运行及题目立即失效；已经接受但未保存的答案仍可由统一“重试未保存操作”重试原操作。清除本地数据会撤销旧世代上下文，迟到结果不能恢复旧分数。多页同时答题只有先提交者获得首次权益。
7. 学习数据保存在当前浏览器；Rust不保存学习档案。预测记录只含公共题目/选项类别、正误、时间和去重摘要，不保存代码、输入、输出、轨迹或内容指纹。浏览器清档是用户主动建立新档案，各题首次权益随新档案重新开始；没有账号终身防作弊承诺。

正式资源1.0.35、SAVE7/DB7、原15个物理分区。原32节/40题172组、20块、七C案例及原奖励身份保持；原始C++内存/算法观察能力不因此变成第21步通用语言学习闭环。实际验证见[验收](../验收/16.1-教学挑战验收.md)及[交接](../交接/16.1-交接.md)。
