# 16.2 同数据双算法对比

从“算法与演示”点击“打开同数据双算法对比”，或进入本地站点的`#/compare`。目前配对原有 C 冒泡排序和选择排序；“互换左右算法”可反转顺序。

1. 在共同输入设置中填写0～30个−999～999的整数，用逗号或空格分隔；空数组填写`[]`。也可按种子与长度生成或复现输入。
2. 点击“应用输入并准备”，两侧分别生成完整实际源码。展开“本侧实际执行源码与当前位置”即可核对。两份输入内容相同，各自独立，不共享可变数组。
3. 点击“运行两种算法”。两侧各真实运行一次；运行完成后从游标0的初始状态开始回放。两次执行顺序收集，共用这次运行的1秒截止；超限显示实际诊断，用户可调整输入并主动重试。
4. 使用统一播放、暂停、前进、后退、速度、滑块、起点与末尾控制。每拍各走一个原子步骤，不表示相同算法阶段。短轨迹先结束后保持末态，另一侧继续；后退会按共同游标完整恢复各自状态。回到起点再播放可重播，不会重新执行算法。

表格显示当前游标的真实累计计数。比较包括循环与控制条件；标量写入包括初始化、循环变量和临时变量；数组写入包括初始化、同值写入。交换是解释器验证的交换观察，相关写入已包含在数组写入内，不能相加当作总操作数。空逻辑数组的源码仍有容量1的占位初始化。

本冒泡模板没有提前退出，最好、平均与最坏比较量都是Θ(n²)，严格大于才相邻交换，因此稳定。选择模板每轮固定扫描，三者也是Θ(n²)，最多n−1次交换，不稳定。辅助空间均为O(1)，不含输入数组和教学轨迹；调速及动画时长不表示算法效率。

输入、种子、长度、算法或生成/重置动作会立即清除整组旧源码和结果。运行中也可展开共同输入修改；旧请求与计时器随即失效。取消会保留已最终接收的一侧，当前及待运行侧停止；新一次运行清除旧组，使用新身份。准备一侧失败时整组须重新准备，不自动重试。切换源码开合不会执行，浏览器页面隐藏时暂停回放。

本页不记录观看、挑战、课程、每日事实或积分；输入、代码、种子和轨迹仅保存在页面内存。离开、刷新或清除本地档案后须重新准备。对比本身不上传学习记录；首次加载仍可能向站点读取静态资源。“本地保存学习记录”与网络加载资源是两回事。
