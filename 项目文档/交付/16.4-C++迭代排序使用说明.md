# C++迭代排序案例

从“算法与演示”中的“C++ · 迭代排序”进入插入、希尔或计数排序。原七个C案例仍在原目录，语言、观看奖励和课程完成条件保持；这三个新C++案例用于观察，不增加积分或课程进度。

1. 输入0～30个十进制整数，以空格或逗号分隔；空数组明确写[]。插入与希尔允许−999～999，计数排序允许−20～20。
2. 点击“运行C++案例”，实际源码中的n替换为输入长度，原序列由cin读入。左侧显示的就是本次交给Rust的同一份C++源码，没有另一份隐藏的C排序程序。
3. 用前进、后退或步骤滑块查看当前状态。播放可选六档速度，暂停后不变化；“回到初态”和“查看末步”只操作已有轨迹。聚焦排序观察区后，空格播放/暂停，左右键单步；输入框等控件保留自身键盘操作。
4. 在“复制完整源码”中选择原文；窄屏通过“实际C++源码/排序观察”页签切换。计数桶可折叠，重新打开不重跑。

插入排序暂存key，右移严格大于它的左侧元素，再填回空位；相等项不越过。希尔排序的gap为⌊n/2⌋再不断减半，最后以1做插入，通常不稳定；它不是其他增量序列的希尔排序。两者使用常数个额外标量，希尔采用保守O(n²)最坏界。

计数排序固定41桶，桶索引=value+20，对应−20～20；先累加，再按桶回填原数组并扣减剩余频率。时间O(n+41)，额外41个int槽=164教学字节，另有常数标量。它没有第二结果数组，也不演示带附加字段记录的稳定性。回填时的桶值是当前剩余次数，不是最初频率。

三例源码和中文讲解均为本项目原创教学内容，没有复制外部题目或第三方程序。知识点分别为：插入的数组边界、短路条件与稳定插入；希尔的整数除法、间隔分组与原地移动；计数的整数偏移映射、频率与空间代价。这些是本案例的概念说明，不新增课程知识实体或图谱完成点。版本化模板分别见[插入](../../content/algorithms/cpp/insertion-sort-1.0.0.cpp)、[希尔](../../content/algorithms/cpp/shell-sort-1.0.0.cpp)、[计数](../../content/algorithms/cpp/counting-sort-1.0.0.cpp)；其中{{n}}只有经过输入校验后才替换为实际长度，页面展示实例化后的可执行原文。

画面中values只显示前n个逻辑输入项，物理容量为30。计数桶显示全部41槽；零、未初始化、当前不存在的对象分别说明。写入边框和文字来自本步真实变化，不把普通赋值说成交换。比较、标量/数组写入计数包含输入、初始化、循环条件和同值写，不能当作只统计元素比较或算法耗时；调速不改变它们。

“当前输出”随游标恢复；“完整执行结果”是另列的终态输出。正常末步对象已经离开作用域，不再显示假活数组；后退可以恢复。运行错误或限制只保留实际有效前缀，没有轨迹时不会保留旧画面。当前案例沿原1秒总执行截止和受支持C++子集，不提供任意代码或完整标准语言运行。
