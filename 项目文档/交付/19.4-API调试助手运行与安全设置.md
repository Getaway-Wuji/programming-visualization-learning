# 19.4 API调试助手运行与安全设置

日期：2026-11-01。当前为1.0.65独立工程交付，19.4仍待真实API验收；19.5未开始。

## 启动已构建的现场

本轮已验证并保留的原生运行现场为 [当前AI设置](http://127.0.0.1:4196/#/settings?panel=ai)，默认关闭、没有Key、未调用官方服务。当前进程由本聊天启动，不是系统服务。自动审批拒绝了停止测试进程并启动另一个后台入口的组合操作（只返回“blocked by policy”），因此没有切换进程或接管端口。若现场已退出，使用下面的已构建启动器重开。

在项目根目录执行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/start-ai.ps1`，启动现有Rust生产网关与正式静态产品。默认入口为 [AI设置](http://127.0.0.1:4173/#/settings?panel=ai)。启动器使用已构建文件，不下载模型、不安装服务、不读取或索取Key。关闭启动窗口或按Ctrl+C停止。

学习数据归属于原浏览器来源。需要继续原学习档案时，必须沿用原来的协议、主机名和端口，使用启动器的 `-Port`、`-Origin`、`-BasePath` 公共参数配置。例如原入口为localhost时不能把127.0.0.1下的空档案当作原档案；不迁移、不导入、不重置学习数据库。端口占用时启动器直接失败，不自动接管已有进程。默认测试入口是新来源，适合独立验收。

若需重建：先用项目固定Node执行 `scripts/build.mjs`，再执行 `cargo +1.99.0 build --manifest-path server/ai-proxy/Cargo.toml --release --locked`。新网关是单独Rust工作区；不改原解释器工作区。开发模式需在原Vite来源启动产品，并在4189运行网关、将网关Origin显式设为该Vite来源；正式交付无需Vite转发。

## 通过产品输入自己的Key

AI默认关闭。打开设置→AI解释（可选），明确选择服务和支持的固定模型，在遮罩输入框输入本人对应服务的Key，点击“验证并启用”。验证仅访问固定官方模型列表，不发送代码或推理请求。当前支持OpenAI `gpt-5.4-mini-2026-03-17`与DeepSeek `deepseek-flash`；API可用性、账号权限和费用以服务方实际状态为准。

Key只在当前标签页内存中，不进入配置、草稿、学习档案、浏览器存储或导出。关闭/清除、刷新、离开工作台、页面卸载、学习数据清除会丢弃Key；服务、模型、Key变更使验证及旧请求失效。另一个标签页不会继承Key。不在聊天、命令行、文件、环境变量或截图中填写Key，不记录其尾号或摘要。输入框在验证后清空。

浏览器只向当前来源的受控Rust网关发送Key专用请求头，网关会看到Key并将其转给选定的固定官方服务。非本机HTTP入口会在发送Key前拒绝；远端部署需要HTTPS和可信的同源网关。纯静态预览没有该网关时，验证失败且保留普通学习功能。

## 每次解释都先审阅再确认

在同一标签页进入C代码工作台，运行自己的受支持C程序，再选择需要解释的位置。面板展示来自原Rust解释器的真实诊断、步骤或同游标状态；点击准备预览不会调用模型。预览列出实际发送的最多两段源码及事实、目标服务/模型、网关可见Key、第三方保留与费用边界，确认发送后才调用API。

只发送预览中的最少片段/事实，不发送完整学习档案、薄弱点汇总、原始输入、完整输出、轨迹或内存。返回文字为辅助解释，未验证建议单独标示；合法factId只能导航到当前原事实，不能改代码、运行代码、评分或发奖励。诊断无轨迹时不虚构变量或步骤。

修改代码、输入、选区、运行或游标会使旧预览/请求失效。取消会停止本端传输与等待，不能保证服务方已开始的推理停止或免除费用。验证总时限10秒，解释总时限60秒，无自动重试、无队列。错误只显示固定本地提示，不转发上游原始错误。

`store:false`不等于服务方零保留。OpenAI默认滥用监控保留政策及例外、DeepSeek公开隐私政策与具体账户/API条款均应在启用及发送前审阅；本项目无法承诺第三方统一零保留、零日志或取消零扣费。固定服务与端点依据见[19.3服务表](../契约/19.3-API-Key服务配置表.json)。

目前官方凭据验证和模型调用均为0次；现有答复测试明确使用模拟响应，不能证明AI质量。需日后由本人在上述产品入口临时输入有效Key，在同一标签页完成真实指针错误、循环和无轨迹语法诊断三类解释，核对原事实引用、未验证建议、失效/取消及错误降级；只记录不含秘密的结果、模型标识与必要行为证据，不抓取Key请求头、浏览器全量网络包或服务端原始错误。完成前19.4不标全验收、任务数量不增加；不因此开始19.5。
