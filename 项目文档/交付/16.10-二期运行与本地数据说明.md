# 二期运行与本地数据说明

本文说明二期已有产品的实际运行边界；验收结论、构建指纹及本轮未测项以独立二期验收报告为准。

## 运行位置与学习资料

React 页面在浏览器内运行。执行、分析、判题和真实轨迹来自受限 Rust/WASM 解释器，在浏览器 Worker 中执行；不运行宿主原生程序，不调用 GCC，不由页面重新计算算法答案。浏览器加载公开课程、示例源码、脚本和 WASM，因此“本地保存”不等于“浏览网页没有网络传输”。本阶段没有账号、登录、云档案、排行榜或多人协作。

学习进度、积分、设置、编辑历史、错题、复习和成就等保存在当前站点来源下的 IndexedDB；保持 SAVE7 / DB7 的 15 个 store。Rust 不保存学习档案。更换浏览器、浏览器用户资料或站点协议/域名/端口，会得到另一份独立档案；普通刷新可继续使用同一来源的资料。无痕模式、浏览器清理、配额不足和损坏会影响保存，界面的未保存或恢复提示应按实际状态处理。不要把一次成功执行等同于已保存通过。

公开课程字节可由浏览器 HTTP 缓存复用，每个使用它的执行环境仍检查完整长度、摘要、版本和封闭结构；缓存摘要不符只在原读取期限内尝试一次重新读取。这里缓存的是公开资源，用户编辑源码、输入、结果和轨迹没有因此新增持久化位置。

## 已有教学路径

保留 32 节 C 课程、40 道练习及 172 组测试、20 种积木和七个 C 案例。代码、积木、权限与编辑历史遵循已冻结子集；不支持的语法会保留编辑稿并给出诊断，不能保证任意 C/C++ 程序都能运行。编译流程页是教学模拟，不能当作宿主编译器输出。Bug 修复关卡的通过依据是真实受限执行及各组结果。

内存、栈和断点观察消费同一条真实轨迹；后退恢复完整状态。虚拟地址是解释器的教学地址，不是设备真实地址。改代码、换输入/题目、离页或清除资料会使旧运行失效；迟到结果不能使它复活。播放速度只改变回放节奏，不代表算法求解速度。

十四个新增 C++ 案例使用页面显示的实际 C++ 源码与相应受限引擎，详细输入域、容量、空满/重复值策略见各案例使用说明和[算法覆盖表](../算法目录覆盖表.md)。它们是有界教学案例，不代表已完成第 21 步的通用 C++ 学习闭环。原七个 C 案例继续使用 C；新算法不通过换标签后执行另一份 C 程序实现。

两个对比族分别为原 C 冒泡/选择，以及 C++ 归并/快速。每侧独立执行，消费相等且隔离的输入副本；统一游标只对齐原子步骤，不表示同拍处于同一算法阶段。原七 C 的 21 道预测挑战、三个固定徽章及奖励去重保持。新增 C++ 观察没有据此增加挑战、学习奖励或每日学习事实。

当前状态快照支持原七 C 和既有内存/递归观察的 JSON、PNG；详见[快照说明](./16.3-当前快照使用说明.md)。JSON 是当时完整状态的独立文件，不是学习档案备份，也不是可导入继续运行的通用程序。新增 C++ 案例没有冒称已接入快照。

## 保存、恢复与清除

使用页面正常完成练习、确认阅读、复习或回答挑战；奖励按真实学习事件去重。失败尝试可以进入错题资料，但不产生通过或完成奖励。配额失败时保留待保存状态，按界面重试；多标签页的清除和资料世代变化会使旧事件失效。

设置页的导出/恢复/清除作用于当前来源的本地资料。先辨认实际目标，清除后不能依靠另一个仍打开的旧页面补发旧通过。快照、公开课程包和学习档案是不同用途的文件，不能互相替代。

## 交付与后续能力

构建使用仓库冻结的 Node/npm、Rust 与 WASM 工具链。按仓库现有构建脚本恢复受审凭据并生成三份引擎、课程公开资源及生产页面；本机旧 `.artifacts` 不应成为隐含交付前提。二期的独立源副本复验明确共享了已安装依赖和工具缓存，不能称为全新电脑安装验收。正式部署需正确提供 WASM/脚本 MIME、HTTPS、压缩和缓存配置；公开资源摘要变化不能靠修改旧凭据放行。

第 17—20 步及追加第 21 步另有任务包。自定义代码的通用闭环、进阶算法课程/多解法、真实 AI 出题调试、笔记导出，以及按 C++→Python→Java 顺序的通用语言支持，均不能因为目录或静态内容存在而宣称已交付。复杂算法只提供 C++ 版的既定边界保留；第 18 步尚余的五个算法见覆盖表。

本阶段没有远端 AI 请求；后续 AI 接入必须另外说明传输范围和实际能力。本轮本地构建/测试不证明 GitHub Actions 已成功，外部 CI 排查交接独立保留。

## 本轮支持矩阵

| 范围 | 实际支持与验证边界 |
|---|---|
| 当前教学内容 | 32节C课程；40练习/172组包含32课程练习与8个Bug关卡；20类积木；7个C案例与14个有限C++案例 |
| 浏览器与平台 | 本轮代表环境为Windows参考笔记本上的Chrome156、minimal主题；Edge/Firefox沿历史记录，本轮没有重新验收 |
| 性能 | 参考设备接交流电、平衡电源、59.951Hz显示，生产构建在限定HTTPS网络下测量；实测与500ms目标偏差见二期报告，不据此承诺任意设备或公网速度 |
| 保存 | 当前来源的SAVE7/DB7/15store；无账号与跨设备云同步。真实存档失败仍须按页面提示重试或恢复 |
| C++ | 仅已列出的受限解释执行子集和有界案例；无Python/Java完整执行，不把语言标签当作语言支持 |
| 部署与离线 | 已测本机生产服务及独立源码构建；没有公网部署、完全离线安装或空白新机安装验收 |
| 输入方式与辅助技术 | 本轮沿既有键盘及状态语义路径；物理DPI、人工缩放、触屏和读屏器没有新增完整验收 |

运行时如遇加载错误，先按页面的明确重试操作处理；公开资源的更新必须匹配当前受审登记。暂态发布错误只会在真实目录与当前档案均验证就绪、且没有待保存事实时解除；配额、冲突、损坏或仍未发布的错误不能由此当作成功。不要通过清空真实学习资料绕过加载或发布问题。
