# 20.2 Markdown笔记下载

1. 打开左侧“学习笔记”，按章节、日期、类型筛选，逐条勾选，再点击“生成笔记预览”。默认不会选择全部个人记录。
2. 在预览末尾填写“笔记标题”，点击“下载 Markdown 压缩包”。标题保留合法中文；文件名中的路径符号等会替换，并自动附时间与唯一编号。
3. 等待“已发起下载”，到浏览器下载列表确认。完整解压ZIP，用普通Markdown阅读器打开“笔记.md”，保持assets和snapshots目录位置。

压缩包中有笔记正文、说明、所选条目的版本与来源；所选快照另有完整PNG图片和同一状态JSON。C与C++标签沿实际内容/运行保留。图片附带完整源码、输入和状态，分享前请核对。普通学习/错题记录没有历史作答源码时会明确提示；当前教材解析另列，不能据此还原旧作答。

打包完全在浏览器中进行，不上传或新增学习记录。最多200条、8份快照；总生成45秒、每图5秒，超量或任一图片失败会停止整包，不漏图后宣称完整。可取消或失败后显式重试。更改标题/选择、清档或离页会撤销正在生成的下载；档案版本变化需要重新核对预览。

“已发起下载”表示已交给浏览器，不表示磁盘保存成功。已下载文件由你管理，刷新或清除网站数据不会删除它们。未发起下载前的选择和临时快照仍遵守20.1的刷新清空边界。

示例：[C与C++笔记ZIP](./20.2-示例/学习笔记-C与C++示例.zip)、[解压后Markdown](./20.2-示例/笔记.md)、[真实错题ZIP](./20.2-示例/真实错题-示例.zip)。示例来自独立测试浏览器中的真实Rust执行，不含用户个人档案。PDF由20.3另行决议，本项不提供PDF或文件导入。
