# 19.3 API-Key 可选AI：配置与后继实施说明

2026-11-01，设计修订2.0.0，**当前产品尚无此设置或API功能**。依据[决议](../架构决策/19.3-API-Key可选AI修订.md)、[数据边界](../架构决策/19.3-API-Key数据流与保留边界.md)、[协议](../契约/19.3-API-Key解释上下文与响应契约.md)。[默认配置示例](./19.3-API-Key默认配置示例.json)只表达设计：disabled/无provider/无Key/无持久化，不能直接拿来启用产品。

## 19.4须实现的设置行为

设置显示“AI解释（可选）”，默认关闭，说明“本标签页临时启用，刷新/退出后关闭；正常学习无需开启”。用户先选受支持服务与模型，再输入自己的API Key；没有预选付费服务，没有内置Key/共享额度。Key输入遮蔽，不提供显示/复制/保存Key按钮，autocomplete=off、spellcheck=false，不将输入值写入DOM属性、控制台、调试状态持久化或截图。

“验证并开启（只发送Key，不发送代码）”按契约执行一次官方models鉴权检查；显示服务方目的地及平台转发方会接触Key。未填、校验失败、转发缺失、模型不可见、限流或网络失败均保持关闭，使用固定错误文案。通过仅意味着当前配置检查通过；解释仍可能因额度、权限、网络或内容限制失败，不能显示“真实AI已验收”。不自动读取环境密钥/浏览器密码/Codex账户，不索取聊天中的Key。

开启后工作台只出现“请求AI解释”入口，用户可检查本次精确代码/真实事实、服务/模型、费用/保留/取消说明，再点击发送。普通执行、暂停、回退、换例、输入编辑不能自动收费调用。AI建议与真实Rust事实分别标明；建议不会自动运行/替换或影响成绩。无Key/关闭时保持普通学习能力，明确说明需要在设置中配置，不放假的AI答案。

关闭或“清除AI配置”取消本端请求、丢弃Key/上下文/结果；刷新、离开工作台/卸载、清学习档案同样处理。修改任一服务/模型/Key使旧验证/答复失效并回到关闭，需重新验证。不要将Key写入localStorage/sessionStorage/IDB/SAVE、URL、JSON配置/导出、日志、截图或错误中。新标签页独立关闭，不能从其他标签页恢复Key。清学习数据广播只通知失效，不携Key；其他标签页收到清除通知也立即取消并丢弃各自AI状态。

## 固定服务适配与交付

[服务表](../契约/19.3-API-Key服务配置表.json)是设计白名单，不是当前自动执行配置。实现前复核模型/参数/官方API与账户条款；按实际需求登记变更，不能通过接受任意URL/兼容供应商避开审查。OpenAI用固定snapshot与strict输出；DeepSeek用登记别名、禁thinking及JSON模式。都只单轮、单连接、无工具、不重试/不换服务，按当时官方价由用户自己的Key账户付费。

需交付同源生产网关、独立Rust转发器、设置/状态、严格schema+语义校验、当前快照提取、逐次预览、引用/跳转、取消/失效/降级；保持原origin、CSP及本地数据身份，不要求学习者手动运行开发服务器，不抢占用户端口。静态发行没有转发能力时如实不可用，不暗中直连第三方；网关/代理/部署链全部按数据边界禁内容和敏感头日志。

先完成不依赖真Key的产品工作与自动检查：默认关闭、settings状态、模拟API契约/预算/错误/取消、同源生产构建、旧档/浏览器多标签页与清档、Key不持久化/不进日志/错误/截图的观察。模拟/哨兵只证明相应失败或接口行为，不证明真实AI。若最后只差真凭据，保留可运行入口与失败证据，再请用户在**产品设置**提供；当前19.3不需要Key，不应为此停住独立工作或在聊天索取秘密。
