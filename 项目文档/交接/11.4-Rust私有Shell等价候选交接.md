## 保持的次序与接口

`atomic_metered` 旧 name/output/state/pending/meta 权重计费不变；`metered_projection` 的 flow_touched、pending、scope、variable、array、output、逐 Initialize scope、最终 flow.len 计费位置不变。即使 shell 不再克隆 output，原 output 权重仍保留。

delta 的最初总 charge、frames→scopes 的每项 charge 与身份断言、对象顺序与 cell/default 分支计费、control→allocator→counters 三次 charge、output charge 保持原顺序。差异只在 charge 后的全字段比较和必要的 Value 构造。没有缓存某一步的验证结果，也没有省略字段比较。

`TraceWire::admit` 仍按 encode_step→encode_point→reserve→check_commit→提交 payload/step/checkpoint/shell 执行；失败时不会提前替换 shell。初始两次编码与初始 checkpoint/reserve 保留。全部 Encoder、Assembly、保留片段、公共 Step/Trace/Judge/checkpoint 类型不变。

TraceWire 的一次初始化仍接受任意已有可信 Runtime 投影，包括 native 原子测试中已布置存活 scope 的状态。初始化标签使用拥有的 `Cow`，每步投影借用原静态标签。该转换只发生一次，不添加 Meter、取消或时钟读取。

## 失败记录与修复

首次新专项 3/3 通过，但既有 COW 回归为 6/7。失败原件保留在 `.artifacts/11.4/rust-shell-cow-regression.log`：新增初始化实现错误假设初始 scope 必须为空，原 COW rollback 测试以已有一个 scope 和 `x=7` 的真实 Machine 投影构造 TraceWire，新增断言在 atomic/计费前失败。

修复产品初始化实现，使其完整转换已有可信 frames/scopes/control/flow/allocator/counters，移除该收窄假设；并将全部 270 组投影加入初始化 round-trip 断言。没有改旧 COW 测试，没有放宽预算或轨迹断言。修复后专项 3/3、旧 COW 7/7 全通过，包含原失败的 program-error/rollback 测试。
