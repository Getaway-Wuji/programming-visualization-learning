# 05.2 语法结构与源码映射落地

2026-10-15（Asia/Shanghai）；Codex-05.2主窗口协调。承接[05.1交接](../交接/05.1-交接.md)，落实P0-C V1.0、STEP-01 / DIAG-01 1.0.0及DEC-004原上限；没有公共契约/依赖版本变化，也不领取05.3或第06步。

## 1. 实际接口与数据

`parser::parse(&str)`和`parse_bytes(&[u8])`先调用唯一Rust词法模块，再解析完整翻译单元；成功返回`Parsed { program, fuel_used, max_syntax_depth, max_ast_depth }`，失败只返回Diagnostic，没有部分AST。词法错误保留其真实阶段与位置；超长/非法编码仍先由05.1检查。

`ast::Program { nodes, root, header_range }`为扁平arena，子边仅存本程序内的NodeId索引，没有递归拥有的子树。Node包含NodeData与原始ByteRange；表达式分整数、名字、索引、一元与二元，声明保存名字范围、可选长度和标量/列表初始化，输出保存单个已解码format及其范围。for的空init/cond/update为None，不创建虚假表达式。显式return保留表达式；隐式main返回留运行阶段的synthetic事件，不伪造源码节点。

Program::from_arena对解析器构造的可信树迭代先序重排并改写所有引用；root=0。内部断言用于发现实现bug，包括环/共享子节点/越界/孤儿与父范围不包含子，不是接收外部JSON的协议验证器。`node_map()`返回STEP闭合种类的`{nodeId,kind,parentId,byteRange}`，n1开始连续分配，根parentId=null；仅序列化该扁平投影，不把内部NodeData冒充EXEC结果。`node(id)`可安全查询合法索引。

先序顺序固定为：函数→主块→源码顺序语句；二元左→右，赋值目标→值，if条件→then→else，while条件→体，for初始化→条件→更新→体，数组初始化项和printf参数按源码顺序。for的源码先序不代表运行时更新先于体执行。ID只在同一sourceRevision有效，动态o/s/f标识以及正式身份校验留06/07。

## 2. 结构接受与拒绝

接受唯一`int main(void){…}`或`int main(){…}`，可选教学stdio行仅一次且在main前。完整消费EOF；函数后额外main、global、header、分号或任何token均拒绝。main原型/参数、用户函数/调用、指针/类型或sizeof、赋值表达式、任意表达式语句、else-if直接链等不支持。

支持每条一对象的int声明，纯表达式和单赋值，独立块/空语句，return expr、break/continue，必须花括号的if/else、while、for。for init仅空/单标量声明/单赋值，cond可空或纯表达式，update仅空/单赋值；不接受数组init、多声明/更新或++/--。条件结构有独立condition节点，表达式仍保持自己的树。

数组长度必须单个十进制Integer token，不能省略、VLA/表达式或多维；有初始化必须非空花括号列表，每项可选单一+/-后跟字面量，无表达式/尾逗号。0长度在语法层保留，正长度与初始化项数量的语义约束交05.3，不能对超容量初值提前冒报解析错。声明31项或更大本身可解析，实际分配预算留运行时。

printf首项必须恰一个字符串字面量，后面只接逗号分隔的纯表达式；相邻字符串拼接、字符串变量/数值表达式或函数返回值不支持。format内容和参数数量只保留待05.3检查。main/printf作为名字的语法位置保留到05.3拒绝；其他保留名、定义/遮蔽/使用、循环外jump、整数组读写、未初始化/越界/除零/溢出不在本轮判断。

表达式优先级从高到低：名字索引→一元+/-/!→*/%→+/-→关系→相等→&&→||。一元右结合，二元左结合；括号改变结构/范围和syntaxDepth，不增加伪算术操作。索引为名字后的一维`[expr]`，不启用完整C的指针/复合后缀语法。短路只保留完整左右语法树，本轮不求值，不声称已产生短路轨迹。

## 3. 深度、定位与诊断

syntaxDepth沿当前结构路径继承：main块=1，每进入嵌套块、控制结构、圆括号或索引方括号+1；控制条件/for头/printf实参的括号也算真实一层。声明数组方括号同样检查。兄弟语句、参数或块不累计深度；独立表达式根最低1，不清零已有块/控制路径。因此main中63层分组=64，子块中63层分组=65；if自身和必需条件括号各增加一层，for内部块按实际块计。

astDepth仅每个表达式根1、子表达式最长路径+1，不包含声明、类型或condition包装。64个左结合加数路径64可用，65拒绝；一元与索引子树同样检查。二元优先级递归只有有限档位，长左链循环构造；语法65进入前检查。尚未构造父节点的长一元/分组前缀另受128活动调用保护，合法63分组+63一元+叶最多127活动调用；最终每Expr构造后再检查AST路径。扁平arena使失败销毁、Clone和比较不按树深度递归。

所有节点范围使用原UTF-8字节0基半开区间，不归一中文/补充面、tab或CR/LF/CRLF，父范围包含子。函数从int起至主块结束，不包含header；块含花括号，普通声明/赋值含分号，for更新不含分号。if/while的condition包含括号；for非空condition范围为实际表达式。分组将表达式根范围扩到括号，但不创造额外kind；format/name保留单独范围。

缺符号E_PARSE_INVALID定位下一实际token，EOF允许零长范围；真实存在的禁用结构E_UNSUPPORTED_SYNTAX，stage=parse。深度超限E_DEPTH_LIMIT同阶段，details带syntaxDepth或astDepth、limit=64/used=64/attempted；无原源码片段或宿主异常。单次失败仅一诊断，无修补/跳过后假成功。

必要05.1兼容修正：原lexer把sizeof在lex拒绝，与冻结NEG-08仅parse/semantic不符。本轮新增内部Keyword::Sizeof保留标记，parser明确拒绝；直接lex能识别该保留词不表示支持sizeof，不能当普通变量。旧测试仅相应改标记断言。其他词法错误原样传递，未修改黄金阶段/错误码或公共Schema。

## 4. 费用与后续接棒

成功fuel_used累计原词法费用、消费token、AST节点构建及子节点访问；它不是完整run fuel或EXEC.stats。失败路径、最终先序重排、node_map/SourceMap、完整检查和编码仍未接统一run meter；06.4必须统一计费/周期截止和终包储备。当前仅验有界源码与解析深度，不冒称完整预算/500ms或取消验收。
