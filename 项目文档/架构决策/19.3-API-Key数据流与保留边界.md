# 19.3 API-Key 数据流与保留边界

AI-DATA-01 **2.0.0**，2026-11-01；仅设计。[替代决议](./19.3-API-Key可选AI修订.md)优先，旧1.0本机路线及验收完整保留历史含义。

## 数据经过哪里

浏览器当前C工作台的已接受真实Rust结果 → 本标签页内存中的最少上下文 → 用户核对当次预览并确认 → 原前端origin的`/api/ai/v2/explain` → 受控Rust转发器 → 所选官方HTTPS Chat Completions接口 → 严格校验后的纯文本解释与允许的factId引用。

Key从遮蔽的设置输入框进入本标签页内存；验证开启或当次解释时，经同源敏感头`X-CViz-API-Key`到受控转发器，转换为所选服务的`Authorization: Bearer …`。**部署方转发器和所选服务方都会接触当次Key；部署方也会接触当次代码/事实**。浏览器不直连第三方API，不把Key给模型消息，不借用平台/Codex凭据，不在标签页之间广播或共享。纯静态发行没有受控入口时保持不可用，不改变origin来绕开，不迁移/复制原学习档案。

“验证并开启”会把Key发给所选服务的固定`models`接口，只检查鉴权与所选模型可见性，不带代码、学习内容或推理请求。用户必须先看到该用途、目的地和Key处理方式；按钮本身是这一次检查的明确动作。失败不发起解释或备用检查，不轮询、不重试。没有模型列表读取权限的受限Key会明确无法完成验证，不改用收费推理探测。

## 每次解释的预览

展示服务名、精确请求model、官方域名及“经本平台同源转发”；实际将发送的1—2段源码（原行号/UTF8字节范围）、真实诊断、所选已执行步与同游标状态（值可能由输入派生）；字节/事实预算和独立60s截止；费用由所填Key账户承担；服务方可能保留已收到的数据，取消不保证免费或删除。设置开关或上次确认不能代替本次确认。代码、输入、运行、游标、选区或配置变化后旧预览失效，重新生成并确认；不能后台静默增加信息。

禁止发送完整学习档案、薄弱点汇总、奖励/徽章、笔记/复习历史、无关文件、原始stdin、完整stdout、整条trace或全量内存/栈。仅发送当前C工作台，不扩大为C++/Python/Java支持。无轨迹时只显示真实诊断与选中源码，明确没有可引用的步骤；不制造失败步骤或失败写入后的状态。

## 各处保留与退出

| 位置 | 允许内容与寿命 | 禁止内容/行为 |
| --- | --- | --- |
| 当前标签页内存 | 暂时Key、配置、预览、当前请求/解释；关闭、刷新、离开工作台/卸载、清除AI或学习数据时作废并释放 | 无“记住Key”；不写localStorage/sessionStorage/IndexedDB、Cookie、URL、历史、剪贴板、导出、日志或遥测；不借其他标签页Key |
| 同源入口/Rust转发器 | 当次Key、已校验上下文/小型响应缓冲，仅请求生命周期；完成/取消/断连/超期丢弃 | 不存Key/会话/上下文/AI历史，不读写学习库；不持久化请求或响应，不落盘代理缓存或调试转储 |
| 官方服务方 | 实际收到的鉴权、模型请求、响应与其政策允许的元数据 | 本平台无法强制服务方零保留、停止推理或退款；不能把`store:false`当作零保留证明 |
| 学习档案 | 原SAVE9/DB9/17store继续本地保存 | 不增加Key、AI开关、AI聊天或请求字段；不因AI输出产生学习事件或奖励 |

释放引用不是内存物理擦除承诺；平台只能约束自身实现与部署配置，不能承诺宿主管理员、浏览器扩展或服务方行为。截图/QA仅用无秘密哨兵与遮蔽输入；禁止记录真Key的后缀、摘要、哈希或错误原文作为“脱敏证据”。

## 服务方披露依据（核对日2026-11-01）

- OpenAI：官方将Chat Completions列为默认不用于训练，默认滥用监测可保留内容至30天，并有法律/安全例外及缓存等状态例外；不把账户可申请的特殊保留控制视为本平台默认已取得。[官方数据控制](https://developers.openai.com/api/docs/guides/your-data)。请求显式`store:false`仅减少可控的应用存储，不能覆盖上述保留。
- DeepSeek：官方隐私页描述保留期限随目的/法律要求变化，并说明下游应用开发者需自行披露其处理规则；未从公开API文档确认可保证的统一API零保留或固定删除时限。本平台明确“不承诺零保留，适用账户/API条款及服务方政策”，不能把普通聊天或开源权重的规则推断为API承诺。[官方隐私政策](https://cdn.deepseek.com/policies/en-US/deepseek-privacy-policy.html)。19.4上线前须复核当时API账户条款及实际披露，有不符则调整清单/重新登记，不能编造已验证。
- 两者均按账户/模型和当时定价计费；本设计不锁汇率、不承诺余额/免费额度、不替用户开通购买。设置和预览显示各服务[官方价格链接](../契约/19.3-API-Key服务配置表.json)，由用户在外部服务管理账户。

## 同源与部署约束

原前端origin不变；生产由受控静态网关供应原构建和相对AI路由，开发可用原Vite同源转发；不能只验开发代理就宣称生产交付。远程部署全程HTTPS，浏览器到同源入口及入口到官方API均校验证书；HTTP仅允许本机loopback开发/发行，不接受局域网明文Key。网关到独立Rust代理限拥有的loopback/私有IPC边界，不开放LAN裸代理；端口冲突不接管用户服务、不自行改origin。

转发器按providerId映射固定方法/域名/端口/路径及model白名单，拒绝任意URL、路径、Host覆盖、HTTP、用户代理环境变量、重定向和未知模型。系统证书验证不能关闭；不允许官方域名解析到loopback/私网/链路本地地址。入口校验精确Origin、Fetch Metadata与JSON类型，仅允许同源，禁止通配CORS及跨站预检。敏感头不进入通用访问日志/trace/APM；反向代理、CDN/WAF、缓存、异常采集均须禁正文/认证头记录；不能部署到无法兑现该边界的通用转发服务。

全部AI响应`Cache-Control: no-store`；浏览器请求不携带学习Cookie，不给Service Worker缓存、后台重试/同步。Rust只重建白名单上游头，不把Cookie/Referer/浏览器身份/关联ID传给服务方；上游鉴权值不回传。日志只允许固定错误码、毫秒/字节/计数等无内容统计，不记录可关联学习身份、请求体、响应体、Key、上游错误原文或headers。

## 取消与失效

浏览器与Rust分别持有当次AbortController/取消令牌；用户取消、断连、关闭、清档、离开工作台或60s截止都立刻作废本地请求身份，终止本端出站连接和等待、释放缓冲；确认本端连接结束后释放单活动槽。此处不再有Ollama进程树/Job Object/keep_alive/终止远端进程的义务或能力。服务方可能已接收请求并继续处理/收费。不能自动重试或换服务以“补偿”取消；用户重新请求必须再次预览确认。

改源、改输入、重跑、移动游标、改选区、改服务/模型/Key、关闭或清档均拒收旧答复；检查`requestId + configRevision + confirmationId + contextId + runRef + inputRevision + cursor`全等及活动代次，晚到结果不能复活。AI失败不影响已接受Rust结果及正常课程。具体闭合报文和错误见[契约](../契约/19.3-API-Key解释上下文与响应契约.md)。
