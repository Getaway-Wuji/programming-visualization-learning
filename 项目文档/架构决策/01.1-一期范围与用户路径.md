## 1. 本次结论与适用边界

一期面向 PC 浏览器，提供无需登录的 C 入门学习和课堂演示。验收主链为：进入课程 → 学习小节 → 搭积木/提交练习 → Rust 真实解释执行 → 单步查看与回退 → 保存完成状态、积分及每日目标。

排期以 SRS 第六章 P0/P1/P2 为基准；其他章节列出的能力不能因此全部挤入一期。Rust 轻量 C 子集解释器、Step DSL、最小练习判定和本地保存是 P0 闭环的必需底座。差异逐项见配套记录，原 SRS 保持原样。

本次固定产品边界、用户路径和完成判定，不冻结执行位置、具体 C 语法/数量、依赖版本、预算、传输协议或本地存档字段；这些分别由 01.2—01.4、02.1—02.3 承接。当前没有产品代码，下列“必须”均指未来交付要求，不是已实现事实。

| L2 | 进入小节，读取目标、讲解、示例与练习要求；明确所需输入和完成条件，可主动确认已学习内容 | 09.1、09.2 |
| L3 | 从小节进入匹配练习，拖拽/修改积木，右侧生成只读 C；基础操作有提示，不要求使用未支持语法 | 10.1、10.2、09.4 |
| L4 | 提交当前程序；Rust 检查并实际执行，按该题约定判定正确/错误，展示诊断或结果；可修正后再次提交 | 05.3、06.1、06.2、07.1、09.3 |
| L5 | 进入本次运行的复盘，用播放/暂停、前进、后退、调速和重播观察代码/变量/数组/输出；返回仍能认出本题与本次结果 | 08.1—08.4、10.3、09.3 |

错误答案、语法/运行错误、取消、资源超限均不能冒充通过。修改积木后，旧运行与判定不作为当前版本成功证据；异步旧响应不能覆盖新程序。已通过的历史练习记录可保留，其结果必须标明所属版本。

存储失败时允许继续临时学习，明确显示“本次未保存”，不能显示“已保存”。清除浏览器数据后进入初始状态；故障反馈、重试及清除影响在 04.3/11.4 验收。

| D4 | 用按钮或空格/方向键暂停、前进、后退，讲解比较/写入与变量输出；调速、重播不改变结果，也不产生重复学习奖励 | 08.1、08.2、08.3、11.1 |

## 6. 小节与练习完成判定

这是内容/学习契约的业务输入，字段与事务实现仍由 02.1/02.3 定义。

| 对象/状态 | 进入条件 | 后续效果及限制 | 任务 |
|---|---|---|---|
| 小节未开始/学习中 | 未开始：没有学习活动；进入小节或开始练习可记录学习中 | 打开页面、滚动、停留、播放示例均不等于完成 | 09.2 |
| 小节内容学习确认 | 用户在小节主动确认已学习目标/讲解；不设强制计时或滚动检测 | 只是完成判定的一部分，不能替代必修练习通过 | 02.1、09.2 |
| 单次练习通过 | 判定绑定题目/内容版本、当前源码/积木版本及当前提交；约定全部测试数据/语义规则通过；需执行的题目由 Rust 正常结束，结果满足规则 | 不能只比较固定源码文本；不能以动画到终点代替题目判定 | 02.1、02.2、09.3 |
| 单次练习未通过 | 当前提交测试不满足、检查/运行错误、取消、超限或无有效判定 | 提供可理解反馈/有效复盘；不发首次通过奖励，不计入当前必修题通过数；旧提交响应须忽略，不改写当前判定或历史通过 | 07.1、09.3、11.1 |
| 练习已通过记录 | 至少一次有效通过，记录归属版本；本地保存成功后可持久恢复 | 之后错误尝试不会抹掉该版本的历史通过；修改后的当前代码不能沿用旧成功标签 | 02.3、04.2、09.3、09.4 |
| 小节完成 | **内容学习已主动确认，且该小节全部必修练习已有与当前内容兼容的有效通过记录** | 每节必须配置至少一道必修练习；缺少/无效练习引用属于内容缺陷，不能自动完成；选做题不阻塞 | 02.1、09.1、09.2、09.4 |
| 已保存/临时完成 | 上述判定成功后，分别显示本地写入成功或保存失败 | 失败可显示本次临时结果，刷新恢复只承诺已成功保存的数据；重试不得重复发事件/奖励 | 02.3、04.1—04.3、11.1 |

小节完成与题目通过是不同学习事件，可以有各自明确奖励来源，但重试、刷新、回退和重复提交不能生成新的首次奖励。兼容的历史通过用于复习；内容升级后是否继续有效由 02.1/02.3 的版本与迁移规则决定，不能悄悄清空进度或把旧解当新解。

案例运行成功/观看完成、每次单步、页面跳转、每日打卡都不能直接替代小节/练习判定。无需强制看完每次复盘才认可一道已正确完成的练习；案例观看奖励的判据、分值、重复学习政策由 02.1/11.1 冻结。
