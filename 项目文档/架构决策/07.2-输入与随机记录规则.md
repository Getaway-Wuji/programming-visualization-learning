## 输入与错误

可视化七个案例按原 `inputSpec.fields` 展示整数或数组：x、n、values、target。数组赋值题的 k/index-in 同样由通用模型支持，练习判题入口仍未开放。课程整数域为−999…999；循环n为0…30；数组按各spec最少项数至30项；索引同时服从字段域和实际数组长度。所有整数必须是安全整数。length-of派生的n不进入values、不提供第二个输入框，由Rust按实际数组长度生成。

手动文本允许带正负号的十进制整数、前导零；数组用空白、英文逗号或中文逗号分隔，可选一对外层方括号。先解析为数值并将负零规范化为0，再按spec检查。空白/缺字段、非数、小数/指数/NaN/Infinity、连续或尾随逗号、越域、超量、未知字段、稀疏数组和非法索引均明确拒绝，不截断、不补默认。每字段文本最多4096个UTF-16码元，超出显示错误。

空数组必须显式填写`[]`或使用“使用空数组”，仅在minItems=0时接受；空白不代表空数组。实际values仍为[]，Rust生成逻辑n=0及C所需容量1的零占位，绝不将占位当输入。二分搜索手动数组必须非递减，允许重复，返回首次匹配；乱序显示错误，不静默排序。随机二分数据生成后按数值升序排列。

错误期间不可准备运行；随机生成、按种子复现及恢复示例仍可用于修正草稿。随机种子和长度错误单独提示。UI错误是输入反馈；Rust再次独立检查values/绑定与实际源码，不依赖前端校验作为可信执行依据。

## generator.c.p0-input@1.0.0

同一spec、种子和长度产生同一values。种子为1…128个Unicode标量值；不trim、不作Unicode归一化，拒绝孤立代理项，按原始UTF-8编码。显示完整种子，生成新种子用浏览器crypto.randomUUID；数据生成器不调用Math.random。

1. FNV-1a32：state初始2166136261；逐UTF-8字节执行`state=imul(state XOR byte,16777619) >>> 0`；最终state为0则替换为0x6d2b79f5。
2. 每次取样依次执行`state ^= state << 13`、`state ^= state >>> 17`、`state ^= state << 5`，结果取无符号32位。
3. 闭区间[min,max]的span=max−min+1，cutoff=floor(2^32/span)×span。丢弃sample≥cutoff后继续取样，返回min+(sample mod span)，避免直接取模偏差。
4. 按spec.fields配置顺序生成普通整数和数组元素。显式length不消耗长度取样；省略length时先在[minItems,maxItems]取样决定长度，再取元素。非递减关系仅在生成时排序。length-of不取样。index-in字段延后，按relations顺序在字段域与[0,实际长度−1]交集中取样，不先生成再覆盖。最终仍通过同一输入校验。

产品UI始终显示并传显式数组长度，默认是示例长度。复现键为generatorRef+inputSpec精确引用+seed+实际values.length（无数组时不传length）；EXEC保留实际values以及原定的random.generatorRef/seed，不新增信封字段。内部API省略length的自动长度行为另有向量，不能与显式长度混淆。独立Python计算的跨实现向量见[07.2随机生成向量](../验收/07.2-随机生成向量.json)。

## 实际源码、请求和失效

前端保留原静态program/exampleInput不变，将实际values的规范JSON字节独立传给Dedicated Worker；`prepare_input`经Rust现有AST输入绑定生成完整C源码和bindingMap。执行请求的source、input.values及random来自同一次准备快照，Rust复核绑定、重新静态检查并真实执行。前端不替换源码字符串、不重算排序/搜索结果。

手动值、seed或长度变化，随机生成、恢复示例、切换案例和清除本地数据，均使旧运行身份及revision失效、终止旧Worker并丢弃旧源码/轨迹。手动修改字段/seed/长度、恢复示例后random=null；只有成功随机生成才附generatorRef/seed。准备失败后的重试保留草稿、seed、length、random整组值；重新准备再执行，不能将示例输入误标为旧随机种子。页面切换/刷新不恢复该组临时数据。

## 保留与兼容边界

source、草稿、实际values、seed、random、诊断和轨迹仅存在当前页面及执行Worker的临时内存。不得写URL、Storage、IndexedDB、Cache、cookie、控制台、网络、日志或稳定指纹；现有学习设置可照常独立存储，不能据此声称整个数据库为空。网页/静态课程/WASM加载仍需网络，代码和输入不发往执行服务器。

EXEC-01/STEP-01/DIAG-01/JUDGE-OBS-01/JSON-INT-01/CONTENT-01仍为1.0.0，依赖及预算不变：源码32KiB、请求64KiB、结果16MiB、燃料100万、轨迹2万步、原1秒总截止、WASM128MiB。07.1大轨迹接收成本由生成静态Schema校验器、有界JSON预扫、原生解析、规范重编码及完整正逆关系检查优化解决；保留取消/截止检查和对坏包的拒绝，不能删轨迹、跳过校验或提高截止来通过。

按CHANGE-01，本轮是预留规则落地及执行prepare适配扩展，不改变旧schema/金样或现有默认prepare调用。主窗口负责合入与影响登记；Rust生产端、前端消费端及真实浏览器双向证据纳入07.2验收。受影响的07.3/08必须继续消费实际values和已验真实轨迹；任务领取时读取本文件及07.2交接。11.4性能基线、07.3纵向门槛、播放器、判题和真实学习奖励均不由本文件验收。
