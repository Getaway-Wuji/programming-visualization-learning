## 1. 冻结结论与规模

一期正式冻结为 **3 章、6 小节、6 道必修练习、4 类基础语法演示、3 个算法案例、20 类教学积木**。六题中循环题包含 while/for 两个必过子目标，仍计一道题。采用既有建议规模，不减少一期闭环；后续内容不得仅凭目录计作交付。

执行语言为 **C 教学子集 P0-C V1.0**，由浏览器 Worker 中同一 Rust/WASM 解释器执行；一期积木→C 单向生成，代码默认只读。支持矩阵是产品开发约束，当前没有解释器/积木实现，不能说“已可执行完整 C”。

教学数据域固定：普通整数参数/序列元素为 -999—999；逻辑序列长度 0—30，数组读写练习至少 1 项；循环计数 n 为 0—30。它们属于本任务的课程/输入约束，**不代替 01.4 的源码、深度、实际内存、步数、输出、轨迹体积与耗时预算**；计算中间值/结果按完整 int32 值域处理，不按输入域截断。

## 3. 整数、表达式与错误语义

- int 值域完整为 [-2147483648, 2147483647]。`+ - *`、一元负号及 `/ %` 的不可表示结果均产生运行溢出诊断；不回绕、不饱和。`INT_MIN / -1` 和 `INT_MIN % -1` 都诊断溢出。两种除数为 0 都诊断除零，失败表达式不写回目标。
- `/` 向 0 截断，`a % b = a - trunc(a/b) * b`（定义用数学整数，不要求按 int32 中间乘法重算）；非零余数与被除数同号。例：`-7 / 3 = -2`、`-7 % 3 = -1`、`7 % -3 = 1`。
- 条件 0 为假，非 0 为真；比较、`!`、`&&`、`||` 产出 int 0/1。`&&` 左假、`||` 左真时不求右边：被跳过的除零、未初始化读、越界不会运行，但未支持语法/名字错误仍在静态检查时拒绝。
- 优先级从高到低：索引读取 → 一元 `+ - !` → `* / %` → `+ -` → `< <= > >=` → `== !=` → `&&` → `||`。一元右结合，其余二元左结合；括号可覆盖。C 的 `a < b < c` 仍按左结合求 0/1 再比较，课程不把它写作数学连锁比较。
- 普通二元操作数、printf 参数按左到右求值以固定诊断和轨迹；赋值先求并检查左侧索引/位置，再求右侧，最后写入。所有表达式无副作用，但错误先后仍明确。此顺序是平台教学约定，不宣称标准 C 普遍保证所有操作数左到右。
- 一期禁用 ++/--、复合赋值及赋值表达式，减少副作用和一行多处写入的歧义；常见计数统一写 `i = i + 1`。合法一元符号连用需留空白/括号，`1--1` 必须识别禁用 -- 后拒绝，`1 - (-1)` 可用。

## 4. 绑定、循环、数组与输出

声明时先创建新绑定并标为未初始化，再求初始化表达式。`int x = x;` 读取新 x，不能偷偷取外层同名值。未初始化变量/数组元素在实际读取时产生运行诊断；单纯赋值不读旧值。所有分支均做静态语法/名字/类型检查，未执行分支不做运行读取。

块退出销毁其绑定，内层遮蔽退出后恢复外层；播放器必须能恢复销毁前后状态。for 初始化声明的变量从声明后贯穿条件、循环体和更新，整个 for 退出才销毁；循环体每次建立新块。continue 先退出体内块，for 执行 update 后再 cond，while 直接重新 cond；break 跳过 for update 并退出最内层循环；return 退出全部块。不存在 goto 绕过声明。

数组无初始化时每个元素独立未初始化；有非空初始化列表时按索引写入所列常量，剩余元素补 0。数组长度与实际资源配额分开：解析认可正长度，分配前再检查预算和大小运算，超资源不能变成宿主分配失败后假成功。

语言越界仅按声明容量 N 检查 `0 <= index < N`。教学 n 是逻辑输入长度；空序列统一显示/执行 `int n = 0; int values[1] = {0};`，占位 0 不是输入数据，算法只处理 [0,n)，柱状图只展示 n 项。`values[0]` 此时在语言层合法，却违反案例的逻辑输入约定；不可把它谎报为 C 越界。

printf 在静态阶段检查字面量格式与 `%d`/int 参数严格对应；`%%` 不占参数。字符串不可含未转义的源码换行或 NUL。运行时先成功求出所有参数、检查输出预算，再一次性追加该调用的虚拟文本；某参数错误/超预算不追加半行。输出写入受限轨迹，不写宿主控制台、不执行 HTML。header 只是教学识别；这里不提供通用 C 标准库或 scanf。
