# 01.1 页面清单

版本：REQ-BASE-01 V1.0；日期：2026-10-14。  
依据：[一期范围与用户路径](./01.1-一期范围与用户路径.md)、SRS §3.1/§3.2/§4.4、03.2 任务卡。

## 1. 页面与导航边界

以下是一期的 **7 类逻辑页面**，用于完整表达入口和行为；不是已经实现的页面，也不是已冻结的路由协议。实际 URL、参数、布局细节由 03.2 统一制定；可在不丢入口、返回关系和状态的前提下合并页面，不为凑页数拆分。

| 页面 ID | 页面及入口 | 必需内容与动作 | 返回/关联关系 | 实现任务 |
|---|---|---|---|---|
| PAGE-01 | 学习首页；默认入口 | 开始/继续学习、课程与案例入口、课程进度、积分/等级、基础形象、今日目标/打卡及历史入口、设置入口 | 进入目录/当前小节/案例/设置；积分明细和目标配置可用面板承载 | 03.2、09.2、11.1、11.2、11.3 |
| PAGE-02 | C 课程章节目录；首页入口 | 章节→小节、目标摘要、未开始/学习中/完成、继续学习和复习；内容缺失反馈 | 进入具体小节，返回首页；不以访问目录产生完成奖励 | 03.2、09.1、09.2 |
| PAGE-03 | 小节学习；课程目录/继续学习入口 | 目标、讲解、代码示例、常见错误、关联案例、必修/选做练习及判定条件、主动学习确认 | 进入匹配练习/案例；返回目录；通过后可继续下一节或复习 | 03.2、09.1、09.2、09.4 |
| PAGE-04 | 练习与积木工作区；小节入口 | 题目/约束/反馈；左积木右生成 C（默认只读）；拖拽/增删/修改；提交、运行、诊断定位、查看本次复盘；当前版本和旧结果可区分 | 复盘进入 PAGE-06，并能返回本题/小节；判定绑定实际提交版本 | 03.2、09.3、09.4、10.1—10.3 |
| PAGE-05 | 算法/语法案例目录；首页/小节入口 | 一期案例说明、支持范围、输入约束、课程关联和进入演示入口 | 进入 PAGE-06；返回首页/关联小节；未交付算法不冒充可运行 | 03.2、08.4、09.1 |
| PAGE-06 | 基础可视化与练习复盘；案例/题目入口 | 左代码右动画；案例模式可输入/随机数据、运行/取消；两种模式均有变量/数组/输出、同步高亮、播放/暂停/前进/后退/重播/调速、文字提示和快捷键 | 案例可编辑输入后重跑；练习复盘固定展示原提交代码/输入/轨迹及本次判定，修改或重提须回工作区；返回保留题目/小节来源 | 03.2、07.1—07.3、08.1—08.4、09.3、10.3 |
| PAGE-07 | 本地设置与数据管理；全局/首页入口 | 基础形象和显示设置、本地保存说明、保存状态/失败提示、数据清除及影响说明；无账户设置 | 返回首页/原页面；清除后刷新相关本地状态；形象和设置刷新保留 | 03.2、04.1—04.3、11.3 |

积分明细、每日目标/打卡历史、形象配置必须可到达；一期可用首页/设置内的面板，不增加独立账户或个人中心体系。执行故障反馈在相应工作区出现，不要求额外“服务管理后台”。

## 2. 跨页面状态要求

| 场景 | 可观察结果 | 责任任务 |
|---|---|---|
| 首次进入、无进度/积分/历史 | 有开始学习和合法默认状态，不显示伪造学习记录 | 04.1、09.2、11.3 |
| 内容加载中/无内容/不存在的内容 ID/失败 | 状态与返回/重试入口可区分；缺失练习不能导致小节自动完成 | 02.1、03.2、03.3、09.2 |
| 执行加载、就绪、播放、暂停、正常结束、诊断失败、取消、超限 | 明确区分；当前运行的代码、数据、游标和输出一致；零步及首尾行为定义清楚 | 02.2、07.1、08.1—08.3 |
| 修改积木或案例输入/切换案例 | 旧运行不可冒充新程序/新输入；异步旧响应不得覆盖当前状态 | 07.1、07.2、10.3 |
| 从练习进入复盘再返回 | 复盘和判定属于同次提交；回到原题/小节，不因播放操作重复奖励 | 09.3、09.4、11.1 |
| 保存成功/损坏/容量不足/不可用/并发写入 | 显示真实保存结果；失败可临时学习，提供恢复路径；清除前说明影响 | 04.1—04.3、11.4 |
| 键盘/输入焦点 | 有可见焦点和文字状态；空格/方向键在播放器可用，输入时不误触；不只靠颜色区分结果 | 03.2、08.2、08.3、11.4 |

本地数据说明必须表达“学习记录保存在此浏览器，可被清除，不跨设备同步”。代码/输入的处理与传输说明引用 01.2 正式决议；在决议前不写“所有数据绝不离开本机”或“完全离线”。

## 3. 不创建的一期页面

- P1 的双向编辑/拆积木、Bug 闯关/编译流程、内存/栈/断点、图谱/卡片/徽章、挑战/比较/快照导出不做一期空入口。
- P2 的自定义代码工作台、进阶课程、语言迁移、薄弱点/AI、笔记导出不做一期空页面；只在后续契约/模块边界保留必要扩展。
- 账号/登录/注册/鉴权、云存档、排行榜、多人房间、班级管理和内容管理后台不在本次三期实现清单。
- 原 SRS 的“预留路由/字段”在一期落实为可扩展导航/模型边界，不创建无法使用的目的页；详见[差异 D-07](./01.1-原需求核对与差异记录.md)。
