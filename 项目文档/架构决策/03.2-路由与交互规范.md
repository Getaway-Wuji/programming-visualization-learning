# 03.2 路由与交互规范

2026-10-14建立，2026-10-15验证交付；Codex-03.2主窗口。输入REQ-BASE-01、DEC-001—006 V1.0、十二项共享契约1.0.0和03.1工程交接。本记录落实03.2，不修改既有共享协议/内容版本/支持范围。

## 1. 路由决定

采用已冻结react-router8.4.0的声明式HashRouter。03.1只有静态交付/预览，未选定具备index回写的托管平台；哈希路由在根目录和VITE_BASE_PATH子目录均不需要业务URL回写，不新增执行HTTP服务。hash之前是实际静态部署目录，之后是页面定位。

| 页面 | 路由（#之后） | 公共参数/返回关系 |
| --- | --- | --- |
| PAGE-01 学习首页 | `/` | panel=points/goals/history打开首页面板；关闭保留首页，恢复打开者焦点 |
| PAGE-02 课程/章节目录 | `/courses`、`/courses/:chapterId` | chapterId为冻结chapter.id；小节指向本章，返回课程或首页 |
| PAGE-03 小节 | `/lessons/:lessonId` | lessonId为冻结lesson.id；必修练习/案例关联来自既定关系；返回原章/目录 |
| PAGE-04 练习积木 | `/practice/:exerciseId` | exerciseId为冻结exercise.id；从其唯一小节进入/返回，复盘同题ID |
| PAGE-05 案例目录 | `/cases` | 4基础演示/3算法规划入口，进入PAGE-06 |
| PAGE-06 案例可视化 | `/visualize/:caseId` | caseId为冻结case.id；返回目录/关联小节；未来输入由当前内存会话维护 |
| PAGE-06 练习复盘 | `/practice/:exerciseId/review` | 同一题目的独立review模式；返回原题/小节，不设置输入或重跑 |
| PAGE-07 本地设置 | `/settings` | panel=avatar/display/data分类；默认data，返回首页或浏览器历史来源 |
| 未知地址/ID | 未匹配路由或非法公开ID | 明确错误与目录/首页返回，不猜测默认内容或产生完成状态 |

目前导航metadata仅包含冻结公开ID、标题、章节/题目/案例关系和规划摘要；不是CONTENT发布包，没有sourceExample/tests/学习事件/实际学习记录。03.3正式内容读取、09.1正文接入时应继续使用同一ID，不能把导航项当作可执行或已学课程。

URL只携带公开定位和面板选择，不放源码、输入/seed、run/submission/sourceRevision、学习档案或返回URL任意字符串。当前复盘没有真实提交即为空态；未来有效复盘只消费同题内存会话，直接地址/刷新不能补造或持久恢复执行轨迹。Hash本身不发送给静态服务器，但这不是对后续所有传输的概括承诺。

## 2. 页面与职责

应用壳为固定全局导航、顶栏与主区，首页预览标记始终清楚。首页可达课程、小节、案例、设置，以及积分明细/每日目标/打卡历史原生面板和基础形象分类。进度、积分、等级显示待接入和破折号，不将默认值冒称实际存档。没有账号/登录、P1/P2空页面或未支持语言执行入口。

小节布局保留学习内容、必修题、关联演示与完成条件区域；内容确认禁用，浏览不产生学习事件。练习区域左积木、右只读代码，下方留提交/反馈区域；没有假积木拖拽或虚构生成源码。案例与review均左代码、右动画区域，下方变量/数组/输出空槽和禁用播放控制；没有预制轨迹或算法重算。

未实现执行/提交/学习确认/目标编辑/形象保存/偏好/清除/播放一律原生disabled并就近解释原因。进入工作区和查看空复盘是实际可用导航，不声称题目已可运行；review没有修改输入、随机或重跑控件。代码textarea值为空，readOnly可聚焦/选择，真正CodeMirror/Blockly生命周期留对应后续任务。

## 3. 状态规范

| 状态 | 实际来源 | 呈现/恢复 |
| --- | --- | --- |
| 页面加载中 | React.lazy真实异步页面资源未完成、Suspense fallback | role=status、aria-busy=true、“正在准备页面”；完成后呈现当前页 |
| 内容/功能空态 | 当前没有正文、编辑器、执行会话或本地适配 | state-empty/role=status，解释待接入/尚无当前运行；有效目录/返回入口仍可用 |
| 页面资源失败 | 实际lazy模块下载/加载失败，PageBoundary接收异常 | state-error/role=alert、“页面加载失败”；“重新加载”重载同地址重试，不把旧页当成功 |
| 未知页面/内容ID | 路由或冻结导航ID查找失败 | 错误标题、文字说明和对应目录返回；无默认题目/奖励 |

加载不由测试query或定时器伪造；验收拦截真实chunk延迟/失败，验证该组件的实际状态。正式内容、WASM模块、C诊断与保存失败属于03.3/04/07，当前页面资源失败不能替代那些任务。

## 4. 交互与视觉

PC优先：216px墨绿侧栏、米白页面、白色卡片，正文深色与灰绿辅助文字，绿色主动作、浅lime路径引导、amber状态提示。中文系统字体不下载外部字体；字号、间距、边框和焦点通过styles.css统一维护。正文不只用颜色区分状态，每个禁用/空/加载/失败都有文字。

1024px及以上练习/可视化维持双栏，列与长文本允许收缩；768px以下导航转顶部、内容及工作区纵向排列，390px验证无整页水平溢出。先左后右的DOM语义顺序保持一致；小屏不隐藏入口或冒称专门移动端功能验收。

首个跳过链接直达main-content而不修改hash；首次加载保留原生Tab顺序，页内导航（包括前后退）在新页标题就绪后聚焦，导航当前页有aria-current及文字。所有实际可交互链接/按钮/textarea/tab有可见focus-visible。首页dialog使用原生模态焦点约束，Escape/关闭按钮关闭、回到打开者；设置采用roving tabindex，方向键/Home/End切换分类并聚焦对应tab。未接入播放器不绑定空格/方向键，避免影响输入；08.2以后另实现真实播放快捷键。

目录/小节/workspace/settings按页分包，首页不导入Blockly、CodeMirror、引擎或完整契约fixture。通用状态/UI和App负责呈现/导航，不承担内容Schema验证、C语义或学习事务。
