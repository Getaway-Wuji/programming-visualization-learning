# 19.3：默认关闭、自备 API Key 的可选 AI（修订）

决议：DEC-P2-011 **2.0.0**；AI-DATA-01 / AI-EXPLAIN-01 **2.0.0**。日期：2026-11-01。派发：`19.3-API-20261101-send1`。性质：19.3 原设计的替代修订，不重复计数，不是19.4产品实现或19.5质量验收。

按守则→需求裁决→台账→第19任务包→19.1/19.2/旧19.3契约与交接读取前置。root在原第19聊天唯一负责本修订；开工23474文件基线见`.artifacts/19.3-api/baseline.json`。只新建本修订前缀的决议、契约、设计样例、配置说明、验收与交接，并维护README、守则、裁决、路线、台账五份中央记录。任务包原文不重写，通过本决议明确解释“密钥不在前端”：禁止内置/共享/构建公开密钥；允许用户在设置中临时输入自己的Key。

## 当前决定

1. AI默认关闭，普通课程、真实Rust执行、回放、薄弱点和规则出题不依赖AI。设置按本标签页提供开关、受支持服务/模型选择和遮蔽的API Key输入。
2. 首批只支持两个固定官方配置：OpenAI `gpt-5.4-mini-2026-03-17`、DeepSeek `deepseek-flash`。这是拟支持清单，**尚未实现或实测模型质量**，不等于替用户选择付费服务；初始provider/model均为空。模型不可用时明确失败，不静默换模型、服务或Key。实现前复核官方支持状态；清单变更须另登记，不接受用户自填URL或任意兼容API。
3. “验证并开启”先本地校验服务、模型、非空Key与同源转发能力，再明确向所选官方`models`接口进行一次鉴权/模型可见性检查；不发送源码，不调用推理。检查失败保持关闭；检查通过才进入可请求状态。它不保证推理权限、额度、区域可用性或模型答案质量，首次解释仍可真实失败。
4. 全部AI设置和Key仅本标签页内存持有，刷新、退出、关闭开关、清除AI配置、清除学习数据均终止本端请求并丢弃AI上下文/结果/Key；其他标签页不共享Key。改变服务/模型/Key先使旧请求与验证失效、回到关闭状态，需重新验证开启。没有“记住Key”，不创建新持久化表或SAVE字段。
5. 浏览器只调用同源受控入口，Key以敏感请求头交给受控Rust转发器；转发器只在请求生命周期持有，将其改为官方Bearer认证。平台部署方会在转发时接触Key和当次上下文，应在设置中明确告知。不能把Key放URL、JSON正文、日志、错误、构建变量、学习档案、导出、遥测或截图；不能复用Codex登录/额度/密钥。
6. 真实诊断、最多2段当前源码和同游标精选事实在每次预览确认后外发给所选第三方，不能沿用旧“仅本机/无外传/零保留”承诺。学习档案仍本地保存，完整薄弱点汇总、奖励、无关源码、原始stdin、完整stdout/trace/内存均不发送。
7. 本端取消中止传输/等待并拒收晚到结果；不能终止服务方进程或保证零扣费、删除其已接收内容。60s硬截止、单并发/零排队、字节预算、事实引用与上下文身份边界继续执行。AI不改写真实轨迹，不自动替换或运行代码，不产生学习判定或奖励。
