## 1. 十份完整参考程序

### REF-01 / EX-01：变量输出

```c
#include <stdio.h>
int main(void) {
    int x = 7;
    printf("%d\n", x);
    return 0;
}
```

预期 stdout：`7\n`，返回0。其余两组见课程清单。

### REF-02 / EX-02：表达式


预期 `17\n`，返回0；x=0/-9 时分别为3/-15。

### REF-03 / EX-03 / DEMO-02：条件

```c
#include <stdio.h>
int main(void) {
    int x = -3;
    if (x >= 0) {
        printf("1\n");
    } else {
        printf("0\n");
    }
    return 0;
}
```

预期 `0\n`，返回0；x=0和5走另一分支，输出1。

### REF-04 / EX-04 / DEMO-03：两个循环子目标

```c
#include <stdio.h>
int main(void) {
    int n = 5;
    int i = 1;
    int sumWhile = 0;
    while (i <= n) {
        sumWhile = sumWhile + i;
        i = i + 1;
    }
    int sumFor = 0;
    for (int j = 1; j <= n; j = j + 1) {
        sumFor = sumFor + j;
    }
    printf("%d\n%d\n", sumWhile, sumFor);
    return 0;
}
```

预期 `15\n15\n`；n=0 两循环均不入体，`0\n0\n`；n=30 为465/465。for后j已销毁，不能再读取。

### REF-05 / EX-05：数组读写

```c
#include <stdio.h>
int main(void) {
    int n = 3;
    int values[3] = {4, 0, -2};
    int k = 1;
    values[k] = values[k] + 1;
    printf("%d\n", values[k]);
    return 0;
}
```

预期 `1\n`，返回前逻辑数组为[4,1,-2]；只有下标1改变。n/k合法性来自题目输入约束，语言越界按数组实际容量3检查。

### REF-06 / EX-06 / DEMO-04：数组遍历求和

```c
#include <stdio.h>
int main(void) {
    int n = 3;
    int values[3] = {3, -1, 2};
    int sum = 0;
    for (int i = 0; i < n; i = i + 1) {
        sum = sum + values[i];
    }
    printf("%d\n", sum);
    return 0;
}
```

预期 `4\n`；空输入须改为可见 `int n = 0; int values[1] = {0};`，输出 `0\n`，不读取数组。课程清单的全部6组均必测。

### REF-07 / DEMO-01：变量赋值

```c

```

### REF-08 / ALG-01：冒泡排序

```c
#include <stdio.h>
int main(void) {
    int n = 3;
    int values[3] = {3, 1, 2};
    for (int end = n - 1; end > 0; end = end - 1) {
        for (int j = 0; j < end; j = j + 1) {
            if (values[j] > values[j + 1]) {
                int temp = values[j];
                values[j] = values[j + 1];
                values[j + 1] = temp;
            }
        }
    }
    for (int i = 0; i < n; i = i + 1) {
        if (i > 0) {
            printf(" ");
        }
        printf("%d", values[i]);
    }
    printf("\n");
    return 0;
}
```

预期 `1 2 3\n`；输入n=0时end=-1，比较/输出循环均不入体，仅输出换行。不添加交换函数、++或前端排序。

### REF-09 / ALG-02：选择排序

```c
#include <stdio.h>
int main(void) {
    int n = 3;
    int values[3] = {3, 1, 2};
    for (int i = 0; i < n - 1; i = i + 1) {
        int minIndex = i;
        for (int j = i + 1; j < n; j = j + 1) {
            if (values[j] < values[minIndex]) {
                minIndex = j;
            }
        }
        if (minIndex != i) {
            int temp = values[i];
            values[i] = values[minIndex];
            values[minIndex] = temp;
        }
    }
    for (int k = 0; k < n; k = k + 1) {
        if (k > 0) {
            printf(" ");
        }
        printf("%d", values[k]);
    }
    printf("\n");
    return 0;
}
```

预期 `1 2 3\n`；相同值不更新最小下标，minIndex==i时不执行交换写入，不承诺稳定排序。

### REF-10 / ALG-03：首次命中二分搜索

```c
#include <stdio.h>
int main(void) {
    int n = 5;
    int values[5] = {-2, 0, 0, 4, 8};
    int target = 0;
    int left = 0;
    int right = n - 1;
    int answer = -1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (values[mid] >= target) {
            if (values[mid] == target) {
                answer = mid;
            }
            right = mid - 1;
        } else {
            left = mid + 1;
        }
    }
    printf("%d\n", answer);
    return 0;
}
```

预期 `1\n`（第一个0）；空输入right=-1，循环不读取占位值，输出-1。乱序输入在案例输入检查阶段拒绝，不使用排序悄悄修正。

## 2. 正常与语义边界样例

表内“片段”放入唯一 `int main(void) { 片段 }`；使用 printf 时带教学 stdio 行。未显式return则按矩阵默认0。字符串中的 `\n` 表示换行转义，预期列同样用转义表示实际输出。

| 样例 ID | 程序/片段 | 冻结预期与观察 |
|---|---|---|
| POS-01 | REF-01 | `7\n`；变量读取/输出 |
| POS-02 | REF-02 | `17\n`；乘法优先于加法 |
| POS-03 | `printf("%d %d %d %d\n", -7/3, -7%3, 7/-3, 7%-3);` | `-2 -1 -2 1\n`；负数除/余 |
| POS-04 | `int z=0; printf("%d %d %d\n", 0 && (1/z), 1 \|\| (1/z), !2);` | `0 1 0\n`；短路不触发除零 |
| POS-05 | `int x=1; { int x=2; printf("%d ",x); } printf("%d\n",x);` | `2 1\n`；遮蔽退出恢复外层 |
| POS-06 | `int s=0; for(int i=0;i<5;i=i+1){ if(i==2){continue;} if(i==3){break;} s=s+i; } printf("%d\n",s);` | `1\n`；continue执行更新、break不执行更新；for变量最终销毁 |
| POS-07 | `int i=0; int s=0; while(i<4){ i=i+1; if(i==2){continue;} s=s+i; } printf("%d\n",s);` | `8\n`；while continue重判条件 |
| POS-08 | `int a[3]={+5,-2}; printf("%d %d %d\n",a[0],a[1],a[2]);` | `5 -2 0\n`；部分初始化补零 |
| POS-09 | `int x; x=4; printf("%d\n",x);` | `4\n`；未初始化绑定可先写再读 |
| POS-10 | `int a[2]; a[1]=7; printf("%d\n",a[1]);` | `7\n`；其他元素仍未初始化，不无故读取 |
| POS-11 | REF-06，n=0/values[1]={0} | `0\n`；逻辑空序列无数组读取 |
| POS-12 | REF-04，n=0 | `0\n0\n`；零次循环 |
| POS-13 | `int lo=(-2147483647-1); int hi=2147483647; printf("%d %d\n",lo,hi);` | `-2147483648 2147483647\n`；完整int32端点 |
| POS-14 | `printf("中文: %d%%\n",50);` | `中文: 50%\n`；中文/%d/%%/换行 |
| POS-15 | 完整程序 `int main(void) { }` | 正常返回0，空输出；具体步数由DSL契约定 |
| POS-16 | `return 7;` | 程序正常结束返回7，不是语言错误；不满足本清单执行练习的return0条件 |
| POS-17 | `printf("%d %d\n",8/4/2,2+3*4);` | `1 14\n`；左结合/优先级 |
| POS-18 | `printf("%d\n",3<2<1);` | `1\n`；左结合，不是数学比较链 |
| POS-19 | `int x; printf("%d\n",1 \|\| x);` | `1\n`；声明存在，右侧未初始化但不实际读取 |
| POS-20 | `printf("前\n"); return 0; printf("后\n");` | `前\n`；返回后不执行，但余下源码仍静态检查 |
| POS-21 | 完整程序 `int main() { return 0; }` | 正常返回0，空输出；另一个受支持入口拼写 |
| POS-22 | REF-01添加中文`// 变量说明`和`/* 输出说明 */`注释，分别使用LF/CRLF换行 | 都为`7\n`，注释不执行；实际定位按各自源码/02.2坐标规则，不沿用另一换行版本的位置 |

| NEG-38 | `int x=(-2147483647-1); int y=x%-1;` | 运行：同样溢出，不返回0冒充有效 |
| NEG-39 | `printf("%d\n",1 \|\| missing);` | 静态语义：名字不存在，短路不跳过静态检查 |

| NEG-41 | `int x=010;` | 前导零/八进制不支持，不误当十进制10 |

## 5. 恢复与未来真实验收
