# 05.1 词法与源码定位落地

日期：2026-10-15（Asia/Shanghai）；协调与最终集成：Codex-05.1主窗口。依第05任务包，落实P0-C V1.0、STEP-01 / DIAG-01 1.0.0与DEC-004 V1.0的词法部分，不新增公共协议或升级依赖。

## 1. 入口与责任

| 文件/API | 本轮实际行为 |
| --- | --- |
| `engine/core/src/lexer.rs`：`lex(&str)`、`lex_bytes(&[u8])` | 先检查UTF-8字节长度≤32768；bytes入口严格UTF-8解码，再迭代扫描；返回`Result<Lexed, Diagnostic>`，失败无token前缀 |
| `Lexed` | 有序tokens及本阶段`fuel_used`；每token有`kind`和原文`byte_range`，末尾唯一零长EOF |
| `TokenKind` | Keyword / Identifier / Integer / StringLiteral / Symbol / IncludeStdio / Eof；字符串内容已解码，范围仍包含原双引号 |
| `engine/core/src/source.rs`：`SourceMap` | 对原文一次线性建边界索引；字节、行列和UTF-16查询二分完成；不归一源码 |
| `engine/core/src/diagnostic.rs` | DIAG-01子集的有界诊断，来源rust，阶段lex/preflight；不包含源码片段、宿主异常或任意JSON |
| `engine/core/src/lib.rs` | 导出三个Rust模块；原`build_probe`和`interpreterReady=false`保持 |

`Keyword`包括int/void/main/printf/if/else/while/for/break/continue/return；main/printf被保留为教学词，变量位置的拒绝由05.3完成。其他已识别C关键字直接报禁用，不能被后续解析器当作普通变量名。ASCII名字只按词法形状处理，`__`/`_[A-Z]`的保留名规则留05.3。

## 2. 接受与拒绝

接受ASCII C空白（空格、tab、VT、FF、LF、CR）、`//`与非嵌套`/* */`注释；注释允许中文和补充平面字符。块注释在第一个`*/`结束；不实现嵌套或反斜杠续行，也不隐式启用完整C预处理。

整数只接受`0`或无前导零的十进制，值0..2147483647；负号独立为token。类似预处理数字的连续候选（含小数点、字母、后缀及指数符号）整体检查，非法形式不会截成成功整数。`(-2147483647 - 1)`能完成词法扫描，`-2147483648`因正数token越界拒绝。

输出字符串允许普通中文及`\n`、`\\`、`\"`三种转义；原始CR/LF/NUL、其他转义或缺闭引号拒绝。格式`%d`、`%%`及参数个数由05.3检查；相邻字符串可分别扫描，但是否拼接/作为合法语句由05.2拒绝，词法成功不等于程序合法。

支持运算符与标点对应C-08—C-10的词法形状。`++`、`--`、复合赋值、移位等按完整最长候选拒绝；`1--1`不会拆成两个负号，`1 - (-1)`正常扫描。孤立禁用位运算、问号、字符字面量等明确报错；未知字符/BOM/非ASCII名字不会被忽略。NUL在源码、注释或字符串中均拒绝。

`#include <stdio.h>`仅作为教学行识别，`#`、include与固定header周围可有横向空白；行中除空白不能含其他内容（包括注释），不展开头文件。IncludeStdio范围从`#`至`>`，尾空白由普通扫描处理；未知宏/头文件/续行拒绝。最多一次及main前位置由05.2检查，05.1不根据token流冒充完整结构校验。

## 3. 定位规则与样例

byteRange为UTF-8字节0基半开区间；行/列1基，按Unicode标量，tab算1列。LF/单CR/CRLF各换行一次；CRLF中间不是合法端点。UTF-16偏移使用原文码元数，补充面字符占2码元；代理对中间也不接受。EOF允许零长范围，末尾换行后保留空行第一列。

直接消费冻结[02.2坐标向量](../契约/02.2-异常与恢复场景.json)中的原文`// 😀中\r\nint main(void) { return 0; }\n`，其中换行转义代表实际字符：

| 字节偏移 | 行 | 标量列 | UTF-16偏移 | 含义 |
| --- | --- | --- | --- | --- |
| 0 | 1 | 1 | 0 | 开头 |
| 3 | 1 | 4 | 3 | 😀前 |
| 7 | 1 | 5 | 5 | 中前 |
| 12 | 2 | 1 | 8 | int前 |

字节4/5/6位于😀内部，8/9位于中内部，11位于CRLF中间，均拒绝。`SourceMap::is_valid_range`同时核对端点合法、顺序与边界；`byte_offset(line,column)`与`byte_offset_utf16`反查同一原文，绝不使用另一换行版本的范围。

## 4. 预算、诊断与下一接口

源码32768字节可用，32769先报E_SOURCE_LIMIT，stage=preflight、synthetic pre-execution、details含sourceBytes/limit=32768/used=0/attempted实际字节数，不扫描/截断。非法UTF-8以E_LEX_INVALID、stage=lex、synthetic pre-execution报告，不把非法编码字节伪装成合法源码范围。普通词法错误直接提供合法byteRange，未知字符范围覆盖整个标量，原始CRLF字符串错误覆盖整对换行。

成功`fuel_used=source UTF-8字节数+token数（含EOF）`，源码限额使本阶段≤65537。扫描与定位均迭代实现，不递归；tokens与字符串总规模受源码限制。此数只表示词法成本，不是EXEC.stats，也未提供完整run meter/截止。失败返回诊断而无用量，SourceMap的独立索引成本也未接入run meter；06.4必须统一累计成功/失败工作、索引与遍历计费及周期截止，保留收尾空间，不能重置词法费用或把本轮验证当完整预算验收。

05.2接收tokens及同一原文构建带稳定nodeId的AST并检查结构、header位置/次数与深度；05.3接名字、作用域、数组与格式检查；06/07再接正式EXEC/运行/Step DSL。当前没有新WASM导出、浏览器提交页、原生C执行、学习事件或用户数据持久化。3章6节6题/4演示3算法/20积木及全部冻结契约/依赖/两锁保持。

验收事实以[本轮验收](../验收/05.1-词法与定位验收.md)和[机器证据](../验收/05.1-词法与定位证据.json)为准；本说明不把词法成功标为C程序成功。
