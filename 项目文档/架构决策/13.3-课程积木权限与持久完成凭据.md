# DEC-P1-006 · 课程积木权限与持久完成凭据

2026-10-30，root；范围仅13.3。前置13.1、09.4、04.3及P0.5-10已验收。

1. 固定20类既有C积木、32节现有课程，不扩语法、课程、奖励或编辑历史。课程`lesson.blockRefs`是本节临时白名单；程序输入声明是题目提供的受控结构，始终保留，不因数组等类型尚未学而破坏骨架。主程序/合成尾返回属于结构，不能据此解锁其他块。
2. 权限为“本节临时白名单 ∪ 已持久完成小节的白名单”。知识点仅随小节教学关系解释，不根据看过内容、答对单题、积分/等级、学习顺序或未来小节推断解锁。允许直接进入任一小节练习其教学白名单；离开后临时权限收回，避免先完成才有必需积木的循环。
3. 本地解锁记录复用SAVE2的`progress:lesson.completed`持久完成凭据。由统一学习事务在确认学习与必修题真实全测通过后产生；不新增重复权限store/Schema，不迁移或重写历史账本。刷新/复习/其他标签页重读同一凭据。保存失败的临时投影不授永久权限，恢复保存后自然生效；清除/换代沿原epoch屏障撤销。
4. 新增独立、版本化权限资源，冻结32节的精确ref、learningRevision、知识点与blockRefs，及受审旧六节的版本/包兼容边。历史grant取历史版本当时白名单，不按新版同名课程新增白名单补发；未知包/版本/revision、仅started/confirmed/passed或案例/奖励记录均不授予。内容升级应追加受审规则，保留旧规则；未知当前版本保稿并禁执行，不能全开兜底。
5. 同一权限用于真实Blockly工具箱置灰、键盘添加与运行/提交前IR检查。代码反推保持真实AST分析，不用前端解析C；未解锁节点源码原样保留，明确列出阻断及学习入口，不退回旧有效程序。输入节点免除只限既有受控input节点；脱离画布块同样检查，不能靠拖拽、复制/undo、代码/隐藏绕过。已存在非法草稿允许删除与修复，不静默删除。
6. Rust/执行契约不变。调用前在PracticeSession重新核当前持久状态；UI禁用仅为提示，不能是唯一权限检查。75份受审源码的必要变更须追加新注册1.0.17，保留1.0.16及旧资源；Chrome与代表主题按用户当前约定验收。单项13.3不触发第13部分Git提交/推送。

实现和验证结果见后继验收与交接；本决议不是验收通过记录。
