## 2. 可选本机适配与原Web入口

普通页面、课程、代码执行和学习存档仍沿DEC-001：浏览器React、Dedicated Worker中的Rust/WASM；无需安装AI组件即可使用。**只有用户选择本机AI时**，后继增加独立Rust本机AI代理和受控的同源HTTP转发。代理不执行C、不访问学习档案，不改原解释器或学习授权。

浏览器继续原本机前端origin和端口，调用相对`/api/ai/v1/*`。现有本机开发/预览服务器的可选服务器端适配转发到`127.0.0.1:47831`，Rust代理再调用自己拥有的Ollama进程`127.0.0.1:47832`。这些端口是设计值，本轮未占用或启动；不改变浏览器origin、不迁移/复制IndexedDB。19.4再登记必要服务器适配/根配置归属并实际验证；不能为接AI另开origin导致已有档案看似消失。

本机生产发行使用受控静态网关提供既有生产Web产物及相对AI路由，不要求学习者安装Node或运行Vite；开发环境才用原开发服务器转发。网关只提供包内受审公共资源，保持原CSP/WASM/内容指纹，不读取用户目录，不变成原生代码执行服务。必须复用用户选定的原本机origin；端口已由其他服务占用时不接管或终止，明确显示未接通并由用户选择受控启动方式。此发行/同源集成由19.4真实验证，当前没有打包或启动新网关。

首批支持当前本机localhost/127.0.0.1前端环境；纯静态站点、远程HTTPS或不具备受控同源转发的入口显示“此入口未连接本机AI”，原功能照常。不得为了可用而扩大CSP、浏览器直连裸Ollama、开放任意CORS或静默增设外部服务。若后续需要公网入口到本机组件，须另审浏览器本机访问权限、跨源与发行方式，不能把本项设计冒称已覆盖。

本机代理只绑定回环，校验固定Host/Origin、JSON类型、大小、方法与版本，拒绝无Origin/`null`/非受控来源；不接受浏览器传入任意URL、模型、模板、路径或任意启动参数。服务器间随机256位短期通道凭据仅存在两个服务器进程内存/子进程受控启动通道，永不进浏览器、`VITE_*`、URL、存档、构建或日志；浏览器不持有模型/代理密钥。本地Ollama本身无需API密钥，仍不能开放监听到局域网。

## 3. 进程、取消与预算（设计冻结）

运行器采用用户主动启动的独立、本项目拥有的standalone进程，不注册开机项、服务或自动更新，不接管已有11434实例。代理每次有效推理使用自己的Windows Job Object管理Ollama及runner子树，模型权重缓存允许保留，用户上下文不落盘。取消/超期/关闭功能/代理退出时终止自有进程子树并丢弃缓冲；不以HTTP断连或`keep_alive:0`冒称已证明推理终止。未确认退出则AI槽保持占用并显示取消未完成，不启动第二个模型；绝不杀用户其他进程。以上为19.4须验证的进程实现条件，当前未创建进程。

| 维度 | 本AI分支冻结值，不改变原解释预算 |
|---|---|
| 启用/请求 | 默认关闭；仅本页临时启用；每次先预览后主动确认，预览60秒过期；刷新/离页/清档/关闭即撤销。 |
| 并发/排队 | 整个本机代理最多1个活动AI任务，排队0；忙时明确拒绝，不自动重试/重发/换模型。 |
| 总时限 | 请求确认起至启动/加载/推理/读取/双端验证/接受合计60秒；正常目标30秒，尚未实测。代理及页面各保留原起点，解码、取消或重试不续时。 |
| 请求/上下文 | 浏览器JSON≤16KiB；2段源码合计≤2048 UTF8字节/32行；≤12个真实事实、≤4个已存在步骤；同游标最多2个对象、合计8个标量/槽值、最多2帧标识。超限先要求缩选，不静默截断。 |
| 模型输入 | 服务器最终发给Ollama的完整JSON≤6144B；`num_ctx=16384`、`num_predict=768`、temperature=0，`stream=false`、`keep_alive=0`，最多系统/当前一次用户消息，无历史。模板/格式预算和实际token计数19.4核验，不把字节数当精确token数。 |
| 输出/解码 | 上游包≤64KiB、assistant content≤8KiB、深度≤12；最终响应≤12KiB；最多4条解释/3条建议；完整终态后验证，拒绝截断/额外字段/未知事实引用，不展示流式半成品。 |
| 资源 | 独立模型GPU/RAM实际占用必须测；不使用或扩大原执行Worker槽/编译缓存/128MiB WASM预算。原执行触发立即使AI失效并请求杀自有模型任务，原Rust不等待AI释放。 |

配置强制`OLLAMA_NO_CLOUD=1`、单模型/单并行、禁调试正文；不传tools、web_search、图片、文件、历史或保留上下文。`/api/chat`格式、流模式与keep_alive有官方文档；它们不是取消/无日志保证，后继仍须独立验证。[chat API](https://docs.ollama.com/api/chat)、[FAQ配置与本地/云区别](https://docs.ollama.com/faq)。

## 4. 最少事实、身份与不可信输出

浏览器仅从**当前已经严格解码接受**的真实advanced结果创建临时contextId，绑定runId/sourceRevision/inputRevision、原build/协议和游标、当前页面lease。inputRevision为新生临时ID，原始stdin不发送；世代/epoch仅本地检查，不向模型发送。用户预览两段真实源码、诊断和选中的同游标值，删减后重新冻结确认。源码变化、输入变化、重新执行、游标变化、改选、取消、刷新/卸载/跨页清除或禁用均使旧context/request失效；新结果不能覆盖新上下文。

发送对象只含当前选择的源码片段、实际诊断码/位置、≤4个已经执行且存在的步骤标识/操作种类及当前游标最少状态事实；不发送整条轨迹、完整内存、原始stdin、完整stdout、学习档案、错题/弱点summary、奖励、身份/世代或其他源码。用户注释和变量内容也是不可信数据，不能作为系统指令；上下文不足时明确说明缺口，不自动扩充、猜测缺失代码或创建事实。

事实文本/值由原Rust轨迹/诊断确定并由页面原样展示。模型只返回“AI解释（可能有误）”及“建议”，只能引用已发送factId；跳转由浏览器查本地证据表，模型不能给任意步、地址或URL。语法错误无轨迹时只送真实诊断和相关片段，不生成step/state事实，不显示步骤跳转。结构化响应只解决形状问题，解释语义仍须真实案例人工/规则核对。

未知、过期、不在预览内的任何引用导致整次模型结果拒绝；不偷偷移到相邻步骤。输出全部按纯文本节点显示，不解释HTML/Markdown链接、不加载模型URL/图片、不插入DOM、不执行工具，不自动替换/运行建议。模型不能改变执行语义、判题、积分或薄弱证据。具体闭合字段和错误码见AI-EXPLAIN-01。

## 5. 可用性与交付界限
