### 必修题判据

参数源块由课程配置关联输入绑定；当前测试把该块的初始化值实例化进显示/执行的同一份代码。学习者修改解答积木，必须保留输入源对象与绑定关系；删除/改名/重复绑定需明确报内容输入错误。参数块约束不是 P1“学完才解锁”机制，不提前实现教学锁定体系。

不按固定源码文本判等。02.1/09.3 落实以下结果与必要教学结构：检查程序 AST 及真实执行所需结构，不能靠未执行分支中的装饰结构满足目标；允许同范围内等价实现。所有冻结测试数据须 Rust 正常结束、main 返回 0、输出严格满足题目格式，错误/取消/超限不通过。有限测试是本题范围内的判据，不是任意程序正确性的证明。

| 题目 | 参数与可修改部分 | 结果谓词 | 必要教学结构 | 参考与必过测试 |
|---|---|---|---|---|

## 3. 输入与生成程序的一致性

- 单值参数和元素在 -999—999；n 为绑定派生的逻辑长度，不要求学习者手填数组尺寸；EX-04 n 是受限计数。EX-05 k 域随 n 变化。空值/非整数/域外/超量输入在提交前明确拒绝，Rust 调用边界也校验；不能截断、补默认值后冒称原输入运行成功。
- 非空序列将 N=n 的十进制常量长度和真实值列表写入代码，例如 `int n = 3; int values[3] = {3, -1, 2};`；不用 VLA `values[n]`。空序列显示 `int n = 0; int values[1] = {0};`，仅占位容量1，视图/算法的逻辑数据仍为空。
- n/数组/目标/索引等输入初始化都进入源码版本；绑定位置、生成节点映射和每组测试实例由 02.1/02.2 定格式。不得只在 Worker 偷改变量值而显示旧模板；判题每组测试也有可核对的实际程序/输入，反馈能关联到失败组与对应轨迹。
- 参数是数据，不拼接未经验证的原始字符串进源码；生成器输出规范十进制值/常量列表。相同积木和同一输入产生相同代码；随机算法、种子格式由 07.2/02.1 冻结，不能用随机动画代替执行。

## 4. 20 类积木与语法映射

| 积木 ID | 类型及可配置项 | 生成范围 / 约束 | 对应子集 |
|---|---|---|---|

| BLK-02 | 整数字面量 | 规范非负 token；负值通过一元负号；最小int边界用显式表达式 | C-03 |

| BLK-05 | 标量赋值 | `name = expr;`，不是值插槽 | C-10 |
| BLK-06 | 一元表达式 | `+ - !`，只接 int 纯表达式 | C-08、09 |
| BLK-07 | 算术表达式 | `+ - * / %`，保留表达式树的括号 | C-08、09 |
| BLK-08 | 比较表达式 | `< <= > >= == !=`，产出int0/1 | C-09 |
| BLK-09 | 逻辑表达式 | `&& \|\|`，保持短路，不生成前端独立逻辑 | C-09 |
| BLK-10 | if / if-else | 条件+花括号内语句列表；else可选 | C-11 |
| BLK-11 | while | 条件+块；允许空体但要有预算诊断 | C-12 |
| BLK-12 | for | init/cond/update专用插槽；不生成++、多赋值或数组声明 | C-13 |
| BLK-13 | break | 只可放最内层循环内合法位置 | C-14 |
| BLK-14 | continue | 只可放循环内；for仍执行更新 | C-14 |
| BLK-15 | 固定数组声明/输入数组 | 正常量长度；可选非空有符号字面量列表；输入显示真实实例化长度和值 | C-15、20 |
| BLK-16 | 数组读取 | 数组绑定+int下标；纯表达式值 | C-16 |
| BLK-17 | 数组写入 | 数组绑定+下标+值，生成赋值语句 | C-10、16 |
| BLK-18 | 有限输出 | 单字面量格式+匹配int表达式；%d/%%与三类转义 | C-17 |
| BLK-19 | return | int表达式；主容器默认返回0，显式return后无继续执行 | C-18 |
| BLK-20 | 独立块/作用域 | 花括号语句列表；可嵌套/为空 | C-07、19 |

槽位类型区分语句、int表达式、循环初始化/更新、常量列表和语句块；缺槽、非法连接、未定义引用明确提示，不生成伪代码。解析器支持的注释/空语句不增加独立积木类。BLK-01 的默认return不能与用户return重排出错，节点/源码映射由 10.2 处理。

生成器对表达式树加足够括号并对一元符号留间隔，保持优先级且不拼成 ++/--。一期教学块不含完整 Scratch 角色/舞台、学习上锁/解锁、双向反推、编辑历史或拆积木；具体积木库/版本由 01.4 选定。
