## 参照与规模

C增量参照[C11公开草案N1570](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf)的6.5.2.2、6.7.6.3、6.8.6.4和6.9.1；C++算法子集参照[C++20公开草案N4861](https://isocpp.org/files/papers/N4861.pdf)的expr.call、dcl.fct、stmt.return及iostream格式输入输出。参照不等于完整标准实现；安全教学语义对未定义行为作确定性错误，并收窄语法。

本任务新增两种语言的执行底座与开发验收样例，以C函数/递归回归及C++汉诺塔、快速排序验证；不增加课程、判题、目录或学习奖励。既有8章32节32题140组及七案例继续用原C路径。16.4—16.9后续新增案例才正式接入本底座，12.4实现可视调用栈；此处的帧/回退消费属于其前置。

## 支持与拒绝矩阵

| 能力 | C函数增量 | 最小算法C++ |
|---|---|---|
| 入口与函数 | int main零参数；用户int/void函数、已定义函数调用与自递归 | 相同；显式language=cpp分派，禁止调用main |
| 参数与返回 | int值传递；int a[]受限数组参数；int表达式返回、void空返回 | 相同的受支持形状，独立语言检查；数组参数是原对象的有界引用，不复制数组、不允许指针算术 |
| 局部状态 | int32、定长一维int数组、块作用域和遮蔽、数组读写 | 同左；bool、字符、浮点及其他类型不在本次范围 |
| 表达式 | + - * / %、比较、逻辑短路、括号、函数调用 | 同左；副作用只经语句/受支持调用发生，不承诺完整标准表达式顺序 |
| 控制 | if/else、while、for、break/continue、return、空语句 | 同左 |
| 输入 | 无隐式宿主stdin；源码中的显式数据初始化 | std::cin >> 标量/数组元素，从请求有界int序列逐项读取；不足给诊断，不访问宿主输入 |
| 输出 | 有限printf字面量（%d、%%、换行）及stdio教学头 | iostream教学头、std::cout插入int/字面量及std::endl；真实C++语法节点执行，不删头/转写为另一份C源码 |
| 不支持 | 指针/取址、结构体、全局变量、原生系统库、宏、变参用户函数 | 另拒绝类/模板/STL容器/异常/new/delete/引用/重载/using namespace及其他标准库 |

不支持的语法在Rust解析/检查中拒绝，包含不可达代码；不接受“本次未执行所以冒称支持”。运行错误覆盖除零、int32溢出、未初始化、越界、缺失返回及非法调用。传参表达式按教学子集规定从左到右求值；不允许利用标准未指定顺序推导可移植结论。函数必须先定义再调用，允许自递归，不支持原型/前向调用或互递归；两种语言均禁止调用main。自增/复合赋值不在此子集，用显式赋值表达循环更新。

数组初始化限有符号int字面量列表，余项补零；C++另允许空`{}`值初始化，C路径拒绝空列表。不支持数组元素依赖或带调用的初始化器。C++20赋值先完整求右侧，再确定左侧位置；C路径保持原教学子集的左位置先求值规则，两者各有实测。C++无大括号的控制体声明建立隐式块寿命，C拒绝声明直接充当该语句；流语法分别要求对应教学头部。

## 预算

每程序最多32个函数（含main）、每函数最多8个参数；活动调用帧最多32层（含main），在创建第33帧前失败，保留前32帧真实前缀。算法教学输入最多30个int、值域-999..999；内部int槽仍为完整int32语义。数组实际分配沿1MiB活槽预算，输入规模不等于数组声明长度。

继承源32KiB、完整请求64KiB、语法/表达式深64、内部燃料1,000,000、教学步骤20,000、活对象1MiB、输出16KiB、完整结果16MiB、安全截止1000ms、WASM最大128MiB；不通过调用重置燃料/时钟/步骤。帧/别名/检查点/逆数据及编码同计预算，取消/到期不得收尾成成功。

独立审查发现仅有“语法64、帧32”仍可能在其组合下耗尽宿主解释器栈，已增加组合执行深度256：同时活动的call/block/stmt/eval入口总数，进入前检查，包含失败路径的返回必须释放。它不是帧上限，简单32层函数调用仍须合法；深块叠加递归在此预算前给E_DEPTH_LIMIT及可逆前缀。原27层块×31层函数的2MiB线程崩溃反例纳入回归，不以宿主stack overflow或WASM trap作为正常预算终态。
