## 2. 可核对场景推演

这些场景只核对设计的一致性和失败/恢复边界，不是已经通过的浏览器行为测试。

| 场景 | 设计预期 | 后续行为验收 |
|---|---|---|
| 正常：加载案例、输入、Rust 运行、播放和判题 | 同源资源下载；本地消息传程序/输入；真实有界轨迹返回，主线程验身份/版本，最少学习事件写本地 | 07.3、08.4、09.4、11.5 |
| 边界：静态模板缓存与用户代码同名 | 仅公开模板缓存；用户执行副本不因名称相同进入静态缓存/URL或日志 | 03.3、07.1、11.4 |
| 边界：Worker 正在同步执行死循环，用户取消 | 主线程直接终止并使运行失效，不能只发取消消息等回复；下次重建 | 06.4、07.1、11.4 |
| 边界：取消/完成消息竞争、编辑后旧结果晚到 | 主线程首个有效终态规则；已接受结果不能被后来的取消改写，未接受的旧结果不通过 | 02.2、07.1、10.3 |
| 失败：语法/运行错误或预算耗尽 | Rust 真实诊断和协议允许的有界前缀，非正常通过 | 05.3、06.4、07.3 |
| 失败：模块下载/编译、Worker 异常或消息版本不匹配 | 基础设施失败类别、重试/返回，无假轨迹/正常结束，无远程回退 | 03.3、07.1、11.4 |
| 恢复：取消后重跑，切换案例 | 新 Worker/新身份，与旧运行数据分离，不重复奖励 | 07.1、08.4、11.1 |
| 恢复：练习→本次复盘→返回原题 | 同题仅内存的临时上下文保留只读提交快照/有效轨迹/当前工作区版本；真正退出或刷新才清理，编辑失效规则仍有效 | 02.2、09.3、09.4 |
| 恢复：实际通过但存储失败、用户清除多标签数据 | 临时通过与未保存分开；清除前的旧写入不能恢复已删档案，统一幂等规则 | 02.3、04.1—04.3 |
| 断网首次打开/缓存未命中/变更 origin | 不能承诺加载或跨 origin 恢复；当前页已加载资源的本地执行不等于完整离线 | 11.4、11.5 |
| Worker 有网络/存储 API 能力 | 以受控导入、适配及发布验证禁止执行内容上传/存档，不能把平台能力说成天然隔离 | 03.3、07.1、11.4 |
| 托管平台保留访问日志或错误报告 | 核验实际配置/保留期；不满足规则则改配置/平台或记录决议，不以规则冒充已关闭 | 03.1、03.3、11.4 |
