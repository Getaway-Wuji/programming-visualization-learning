# 仓库文件范围

提交产品源码、课程资源、必要协议、回归测试及固定输入、依赖锁、构建与部署配置、面向使用者的文档。

AI 技能、AGENTS/SKILL 指令、交接、分任务要求、进度台账、工作规划、临时设计稿、原始验收截图/日志、一次性生成脚本、本机工具、缓存及教材 PDF 仅在本机保存。禁止通过 `git add -f` 或重新命名绕过此规则。后续任务不得把进度和交接追加到 README。

新增必要测试数据时，只保留测试实际读取的最小输入，置于 `tests/fixtures/` 或 `shared/`；不附带整个验收目录或 AI 工作过程。历史发布元数据保留旧学习身份，当前构建只检查产品输入清单和真实 WASM。

提交前运行 `check:repository`，检查暂存文件和整个待推送提交链。清理采用普通追加提交，不改写历史；旧提交仍可查看曾经上传的文件。
