# 算法可视化

从“算法与演示”选择模块，修改数据后运行，使用播放、前进、后退和进度条查看状态。键盘空格控制播放，左右方向键单步；点击代码行号可设置断点。阅读代码时，高亮会在代码面板内跟随当前位置。

目录包含排序、查找、数据结构、树与图、动态规划、经典算法六类，共40个模块。交互参考[数据结构与算法动画](https://study-hard-racate.github.io/)，本目录的C++程序为本项目独立实现，由现有受限Rust/WASM解释器执行。柱形、节点、连接、状态表和输出都取自同一份执行轨迹；浏览器绘图不另行计算算法答案。

每个模块显示实际支持的输入范围。一般序列最多12项，树节点最多7项；计数排序使用0～20，基数排序使用0～999。图最多6节点、8边、正权1～9；最短路无穷距离显示为∞。字符例子使用最多8个小写字母，Trie使用a、b、c。背包容量0～8、最多4种物品，汉诺塔0～5盘。范围用于保持逐步观察清晰，与完整语言或任意规模算法执行能力分开。

修改输入后原轨迹失效。运行和播放不改变课程完成记录或授予积分。代码执行、资源预算、虚拟地址和个人学习数据存储继续沿用平台现有约定。
