# C Primer Plus 第六版主题原创课包

独立包 `content.c.primer6@1.0.0`，契约 `CONTENT2.0.0`。来源是用户确认的本地第六版中文书，按原章/节标题、层级、顺序和物理页定位编写原创解释、题目及示例。私有原书、提取正文、截图不进入产品或公开资产。书籍权利属于原权利人；本课包不是原书全文，也不声明原书授权转载。

650 正文节点，404 教学课、793 活动、232 示例、44 判题题目、421 知识节点。17 主章提供教学；A 答案和全部 B 内容只作参考，均无教学身份、学习进度或奖励。19 个内部正文块按需加载，清单绑定每块 SHA/字节数及精确引用目录。

124 可执行例和 7 诊断例由真实 C6 Rust/WASM 验证；101 阅读例有完整代码和具体阅读边界，多文件程序包含伴随源码。44 题四组参考解全部通过，44 份初始程序正常执行但未达到题目要求；345 来源设计检查不授予原书编程题完成。正文及题目由模型逐项独立阅读核对，审校记录明确不是外部真人审核。

`scripts/c6-course/publish.py --evidence 项目文档/验收/21.4-C教材执行验证.json --check` 检查原创输入、逐项审校和真实执行证据的新鲜度与确定性。`scripts/c6-course/build-content.mjs` 在发布时验证清单固定 SHA、闭合 Schema、全部实体引用、438 份压缩原始执行包及预算后复制 20 个 JSON 到 public；浏览器只消费预编译校验器，不动态编译 Schema。

21.4 交付内容与底层惰性仓库。公开新课入口、用户学习保存、迁移、奖励、草稿和导出由 21.5 整合；旧公开课包及 SAVE9/DB9/17 stores 保持。详见 `项目文档/契约/21.4-C教材CONTENT2与参考资料契约.md`。
