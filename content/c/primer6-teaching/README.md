# C 课程正文包

本目录是 CONTENT3.0.0 / `content.c.primer6@2.0.0` 的规范内容输入和惰性加载资源。`source-2.0.0.json` 包含正文、完整教学程序、来源例、选做指导及执行练习；构建由它确定生成清单和 19 个章节/参考资源块。

课程有 404 节、505 份教学正文和 576 处完整教学程序呈现，共用 386 套完整程序。A/B 的 111 个节点仅供参考。345 项来源指导为选做；44 项执行练习沿用原判题目标，每项四组。新正文的引用版本为 2.0.0，Rust 判题的 profile/program 和 owner package 仍明确使用 1.0.0。

`execute` 程序使用 Rust 真实执行，`diagnostic` 明确区分执行诊断与正常执行后的业务错误，`reading` 保留完整标准 C 程序及阅读边界。正文代码不经前端算法重算或动态执行。

运行 `node scripts/c6-course/build-teaching-content.mjs` 验证规范输入、闭合引用、固定发布绑定及确定性产物，并复制公开 JSON；`--inspect` 只检查和报告预算。发布绑定更新使用显式 `--write`。普通构建仅消费产品资源，不读取本机教材 PDF、写作文件或审校原件。

总资源预算 20 MiB，清单 256 KiB，单块 1 MiB，每套程序 32 KiB。读取器按需取清单和目标块，验证 UTF-8、体积、版本及哈希，错误不会回退为旧版课程。
